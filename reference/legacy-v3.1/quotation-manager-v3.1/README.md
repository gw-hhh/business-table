# 报价管理 3.1.0 · 体验精修版

基于用户已确认的 3.0 完整源码进行修改，不用早期原型替换。新增的是设置表达、预览与反馈能力；原有业务流程、列规则和数据工具均保留。界面默认继续采用蓝色主题、原生 JavaScript / CSS，不依赖 CDN 或在线字体。

## 本轮变化

### 1. 统一默认尺寸和阅读层级

默认常规控件 36px、正文 14px、辅助信息以 12–13px 为主。表头约 44px，默认双行记录约 60px。紧凑/默认/宽松三档继续存在；较大字号、长文本和富文本按内容撑开，不截断记录来强凑行高。客户副标题采用更深的默认文字色。用户已设置的列字号、颜色、字重、列宽及格式不会被清空。

表头排序/筛选/更多入口预留位置，悬停不再挤动列名。左右冻结继续使用原有两个图标，不改成下拉框。批量选行、区域选择、业务条件标记保留各自表达。

### 2. 设置抽屉

- 固定显示当前编辑列及字段类别/显示状态；批量勾选明确标注为“批量样式”，不与显隐混淆。
- 切换列或分类时保留本次打开期间的滚动位置；搜索字体对话框关闭后返回原控件。
- 顶部显示未应用的修改摘要，“查看修改”可以定位到相关列/分区。
- 无变更时“应用”禁用；快捷列面板带入的未确认修改仍算待应用变更，可以直接应用。
- 输入错误保留草稿，显示就地错误并提供定位入口。表格设置草稿仍然在确认后才进入应用状态。
- 每列的筛选/映射/数字/模板/试算支持摘要和折叠；快捷定位会展开目标分区。

### 3. 工具栏配置与映射

桌面工具栏配置改为统一表头的紧凑列表。保留名称、顺序、直接显示/更多/隐藏、展示形式、固定、分隔和上下移动。320px、390px 窄屏使用明确分行，而不是让“形式”选择器掉进拖动手柄的小格。

映射先显示“原值 → 文字 → 即时样例”，每项的颜色、背景、边框与图标在“样式”中展开。空值、未匹配提示和所有原有字典选项保留。颜色仍可用原生选择器、完整六位色值编辑；增加常用色板。

### 4. 当前对象预览与整表预览

- 工具栏：页面/表格两组，以及窄幅 320px 下的溢出“更多”。
- 操作按钮：行内按钮、宽度不足收起、更多和导出子菜单；只作预览，不执行保存、删除或下载。
- 映射：当前编辑项、其他样例、空值和未匹配值。
- 数字和试算：原值、显示结果、Excel 数值及数字格式。试算输入同步到底部预览，不再固定使用第一条报价。
- 列/模板：选择真实样例记录，查看当前列；可切换整表。

整表及当前列的表格预览复用正式 `QuoteTable` 渲染及密度。预览表格不绑定业务事件，并使用 inert 防止交互；操作按钮预览则使用专门的无副作用回调。

预览可收起；展开状态和当前对象/整表模式保存在独立的 `quotation-demo:experience:v1` 中。它不是报价数据，也不参与表格设置 JSON；存储失败只影响这项界面记忆。打开设置本身不会为了记忆状态而写入业务偏好。

### 5. 更适合具体任务的控件

表头/内容/按钮对齐新增分段选择及左右方向键切换；字体仍可用原下拉框，另增加搜索选择入口。数字格式增加“固定小数/最多小数”快捷设置，原最少、最多小数位输入继续保留，方便细调。

### 6. 富文本

按“撤销重做、字体字号、文字格式、颜色、段落列表、插入清除”分组。常用文字样式采用熟悉字形并提供明确可访问名称。加粗/斜体等显示选区状态；混合格式明确提示，不误报为统一格式。设置格式时保留选区；中文输入合成处理、撤销/重做和粘贴清洗沿用并回归验证。

默认编辑窗口较紧凑，支持“展开编辑”。备注确认按钮为“回填备注”，与报价表单的“保存报价”区分。模板仍只回填表格设置草稿，应用设置后才生效。普通备注输入、字段模板、列表、安全链接和原资源限制均保留。

## 原有能力与边界

保留新增、修改、详情、复制、删除、批量选择、查询、分页、多字段排序、列自定义、命名视图、工具栏、行操作和二级菜单、列筛选、映射、数字规则、富文本、分组、对比、条件标记、区域选择、历史、真实 CSV/XLSX 导出、导出预览/方案、模板与 JSON 备份恢复。

仍是本地前端演示，不含真实后端登录、权限、审批、Excel 导入、批量修改和后台任务；本次不增加空按钮来替代这些能力。富文本仍为轻量原生编辑器，不是完整 Word，不支持图片、视频、任意 HTML/CSS/脚本。只读预览不是权限校验。

## 使用与升级

查看效果：用浏览器打开 `quotation-manager.html`。开发源码：`index.html` + `src/`。聊天中的预览不一定执行脚本，需保存后在浏览器中打开。

升级前在旧版分别备份“报价数据 JSON”和“表格设置 JSON”。继续沿用 `quotation-demo:data:v1`、`quotation-demo:preferences:v1` 和 schema 3；读取旧 schema 2/3，不通过升级重置个人配置。不同站点来源、浏览器或 `file:` 路径不保证共享本地存储。

建议在固定站点来源测试升级；原业务数据和设置备份不能相互替代。新版本不自动改写数据库字段、业务状态编码或金额精度。

```bash
# 源码开发（使用本地静态服务）
python3 -m http.server 8080 --bind 127.0.0.1
# Windows 有 Python 启动器时可用：py -m http.server 8080 --bind 127.0.0.1

# Node.js 18 或以上；构建及单元测试不需安装产品依赖
npm run build
npm test

# 全部浏览器及逻辑回归，需 Python Playwright 与 Chromium
npm run test:all
npm run test:visual
npm run test:navigation

# 独立读取导出的工作簿，需 openpyxl
npm run test:workbooks:portable
# 可选 artifact_tool 读取及渲染（需其运行服务正常启动）
npm run test:workbooks
```

完整 HTML 由同一套源码构建，不应与 src 各维护一套。浏览器测试可以使用 `CHROMIUM_PATH` 指定 Chromium。

## 新增源码职责

| 文件 | 作用 |
|---|---|
| `src/experience.js` | 修改摘要、规则摘要、对齐分段、字体搜索、色板和预览偏好 |
| `src/settings-preview.js` | 当前对象/整表预览与只读交互 |

| `tests/experience.test.cjs` | 摘要及配置验证 |
| `tests/polish_browser_test.py` | 31 项体验专项测试 |
| `tests/polish_screenshots.py` | 多视口实际截图与布局尺寸记录 |

其他文件在原有模块内作最小接入：`settings.js`、`rule-settings.js`、`rich-text.js`、`table.js`、`actions.js`、`app.js` 等。不替换原有数据仓库或导出模块。
