# 3.1 默认表现规范

这些是项目的默认值，不会覆盖个人列配置，不代表整个页面通过无障碍认证。

| 用途 | 默认 |
|---|---|
| 页面标题 | 22px / 600 |
| 设置标题 / 当前列 | 16px / 24px 行高 |
| 正文 / 输入 | 14px |
| 辅助说明 | 12–13px（极窄屏部分补充标签保持紧凑） |
| 常规控件 | 36px，局部紧凑控件 30–32px |
| 主表头 | 44px |
| 默认单行最小高 | 48px |
| 默认双行样例 | 约 60px |
| 紧凑最小高 | 44px |
| 宽松最小高 | 72px |
| 主颜色 | #2468e8 |
| 辅助正文 | #64748b |
| 控件 / 面板圆角 | 6px / 8px |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32px |

行高由内容与字号共同决定，不按固定高度裁掉长内容。状态颜色和列内联设置仍按业务/个人配置优先。预览复用真实表格渲染；对象预览只展示当前相关配置，不执行真实业务回调。

响应式将工具配置显式划分为名称行、位置/形式行、固定/分隔/移动行。表格及预览等二维内容各自滚动，普通表单不应撑宽整个页面。
