## 4. XLSX 独立读取

openpyxl 3.1.5 读取 6 个文件：业务导出、空白模板、示例模板、映射显示值与原值、两种百分比数值、缩放金额与合计。检查工作表数量、编号文本类型、金额数值、空白填写区、映射文字和编码、百分比 `.1234` 与原值 `12.34`、缩放后 `6.386` 和缓存合计 `102.645`，并检查百分比格式与合计公式类型。

这些验证表明受测文件可被独立解析且测试的值/类型正确，不等于在 Excel/WPS 桌面获得像素一致排版。原 artifact_tool 验证脚本保留，没有将其失败改写为通过；本轮新增本地可运行的 openpyxl 检查作为额外证据。

## 5. 本轮发现并修复的问题

首次回归发现稳定表头图标槽挤压默认负责人标题约 2px，已收紧同组间距且不放宽原断言。无变化禁用应用后，修复快捷面板草稿与已应用基线混淆、批量样式摘要未刷新。上方试算值和下方预览原先不同步，已使用同一样例。截图还发现固定标题滚动内边距与分区滚动外边距相加，定位留下约 122px 空白，新增失败用例后修复。

旧浏览器用例只调整操作方式：对齐改点分段控件；焦点循环从初始已禁用的应用按钮改为取消；迁移用例先做无关的列名修改再保存，以符合“没有修改不保存”的新规则，原冻结、列宽和排序断言继续保留。没有删除旧业务断言。

早期并行浏览器检查出现一次 `set_content` 2500ms 超时；最终完整回归为串行且退出码 0。中间失败记录保留在 `polish/`，以最终完整日志为准。自检为本会话代码与截图检查，未使用独立审查子代理。
