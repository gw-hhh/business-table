# 3.0.0 实现者复查

没有可用的独立代码审查代理；此记录是实现者检查，不宣称外部独立审查。

## 保留与边界
- 使用上一版完整 ZIP 作为基线；原始上传和旧交付文件未覆盖。
- 配置归一化集中在 column-rules/customization/core；稳定字段 key、原状态和整数分模型保留。
- 所有旧功能和旧测试保留。旧测试只更新 schema 版本以及设置页由4变5的精确断言。
- 不把显示设置、隐藏操作或筛选当作权限；不添加未实现的业务按钮。

## 已发现并修正
- 数值精确筛选与百分比/单位的比较基数。
- 恢复配置不会先悄悄丢掉查询，需在应用时确认不兼容条件。
- 富文本颜色重复覆盖、裸文本段落对齐和列表序列化。
- 危险粘贴转换为受控节点，增加长度/节点/层级限制。
- 字段模板空内容检查；备注纯文本与格式数据一致性校验。
- 缩放合计与原值导出单位一致；百分比显示列不默认求和。
- 窄屏快捷列设置默认固定，完整设置入口始终可达。
- 顶部提示移至中央，避免关闭按钮拦截新工具栏入口，保留可关闭提示。

## 已知取舍
- 原生轻量编辑器，而非 Quill/完整办公文档编辑器；不支持图片、媒体和任意HTML。
- 组合条件单层；分组报告只读且只面向本地数据，不是虚拟化大数据引擎。
- 配置历史不是业务审计；区域选择没有粘贴写入。
- Excel导入、批量修改、打印模板、正式权限/同步不在本交付中。
- 真实导航、真实会话存储和办公软件兼容性须按测试报告补测。
