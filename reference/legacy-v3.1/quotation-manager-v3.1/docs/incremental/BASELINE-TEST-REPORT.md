浏览器实际下载文件后，使用 Python 标准库检查 ZIP 中央目录/CRC 和 XML；检查编号、金额、日期、列名、字段顺序、样式颜色、合计公式与模板工作表。

该检查不同于在 Microsoft Excel 或 WPS 桌面应用打开；**本轮未验证这些应用的实际兼容表现**。

另外执行了 10000 条记录的 Node 导出冒烟检查，生成字节数组长度 7047924；该次记录耗时约 398ms，仅属于本测试环境，不是手机/浏览器性能保证或生产服务承诺。没有据此宣称大规模业务性能已经验证。

检查并修正了预览空节点字面量、重复焦点键、状态字号/字重继承、非法 XML 字符、末行菜单被延迟 scroll 关闭、提示文字拦截点击、默认金额/负责人表头被菜单入口挤压等问题，并加入对应回归。
