## 关键约束
- 原始状态仍为 draft/review/contract，不转换真实数据来满足示例。
- 金额仍为整数分；显示不截断原始数据，百分比显式声明基数。
- 所有新配置须能归一化、校验、取消、持久化和备份往返。
- 筛选选项来源于完整本地集合；字段与条件不是权限。
- 富文本是受控 Delta，渲染用 DOM；只允许受控字段和样式，不执行用户 HTML/JS。
- 编辑器采用原生 Selection/Range + 受控结构化文档；不是 Quill。使用本机字体，不附带字体文件。依赖下载失败后的决定记录见 PROGRESS.md。

- 本轮不将前端演示宣称为后端权限、跨设备同步或生产审批系统。
