1. 复用 QuoteTable 的预览路径跳过事件/ResizeObserver 注册，避免每次输入生成新的业务监听。预览宿主 ResizeObserver 在关闭时销毁。真实操作仅使用无副作用回调。
2. 原有冻结图标 SVG、数据仓库、金额精度、导出字段/范围及模板结构未替换；所有旧测试保留。
3. 首轮回归发现默认负责人表头被固定图标槽挤窄 2px。修正同组图标间距，保留稳定占位，不放宽“默认标题完整显示”的断言。
4. 禁用无变化的应用按钮后，补上快捷列面板已修改草稿与实际已应用基线的区分；针对这个入口先测失败再修复。
5. 无源列编辑的批量样式复制也需要更新修改摘要/按钮状态，补上专项回归。
6. 当前对象预览与试算原始值同步，避免上方试算与下方第一条报价结果矛盾。
7. 颜色、映射、列名称、工具名称错误定位到对应字段；颜色与HTML仍按受控数据输出。
8. 原测试调整三类操作方式：对齐从下拉选择变为点击分段；初始无修改的焦点测试从禁用应用按钮改为可操作的取消按钮。迁移测试先作一次真实的无关列名修改再保存，以验证新 schema 持久化；原冻结/列宽/排序断言仍保留。所有原有业务断言继续保留。
9. 测试期间并行浏览器启动曾出现一次 set_content 2500ms 超时；保留日志，最终完整回归串行运行，不凭旧报告作通过结论。

10. 截图检查发现固定标题的 scroll-padding 与目标分区 scroll-margin 同时生效，导致定位后多留 122px 空白。新增定位间距测试先失败，再只保留容器滚动内边距，避免占用编辑区域。
