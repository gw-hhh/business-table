# 报价管理 3.0.0 · 列规则与富文本增量版

在 2.0.0 完整自定义版本上继续增量修改，不用早期原型替代。保留原生 JavaScript + CSS、原始六条示例报价、整数分金额模型、本地数据仓库、查询、新增编辑、分页、批量选择、视图和备份恢复。

本版是本地前端演示，不包含登录认证、后端接口、真实权限、审批、转合同或 Excel 导入。隐藏按钮只是显示偏好，不代表权限控制。

## 1. 打开与开发

### 看效果

用浏览器打开 `quotation-manager.html`。这是完整单文件，样式和脚本均已嵌入，不需要构建，不加载 CDN、在线字体或外部 JavaScript。外观字体使用本机字体及后备字体，不附带任何字体文件。

聊天中的文件预览不一定执行 JavaScript；请将文件保存到本地后用浏览器打开。

### 修改源码

直接修改 `src/`，通过 `index.html` 运行分文件版本。为获得固定的浏览器存储来源，建议用本地静态服务：

```bash
# macOS / Linux，有 Python 3 时
python3 -m http.server 8080 --bind 127.0.0.1

# Windows，安装了 Python 启动器时
py -m http.server 8080 --bind 127.0.0.1
```

浏览器访问本地 `http://127.0.0.1:8080/index.html`。也可放入自己的 .NET / IIS 静态站点；本版不要求特定后端。

生成单文件：

```bash
# Node.js 18 或以上；构建和单元测试无需 npm install
npm run build
npm test
```

`quotation-manager.html` 始终由同一份源码生成。不要同时手工修改单文件和分文件源码。

### 原有数据

沿用原存储键：`quotation-demo:data:v1` 与 `quotation-demo:preferences:v1`。旧列宽、显示、冻结、行高、单字段排序和视图会补齐新配置；报价数据结构不因列重命名而改变。

兼容旧配置不等于跨浏览器、跨站点自动搬迁数据。直接打开不同路径的 HTML，浏览器可能分配不同的存储空间；修改前建议在旧页面“数据与说明 → 备份报价数据（JSON）”导出备份。在同一站点来源更新文件更便于读取原设置。JSON 报价备份不包含个人表格设置；新版提供单独的设置备份。

## 2. 设置入口

- **列设置快捷面板**：显示/隐藏、顺序、左右冻结图标、恢复默认、取消、确认。左/右冻结按钮互斥，同侧再次点击取消冻结；已冻结的图标保持可见。编号始终显示。
- **表格设置**：右侧完整抽屉，包含“列设置 / 排序规则 / 操作按钮 / 表格外观 / 工具栏”。快捷面板的“更多设置”会把当前未确认的列草稿带入抽屉。
- **表头菜单**：右键表头，或点击表头悬停时出现的更多图标，可重命名、排序、冻结、恢复列宽和设置此列。

完整设置只修改草稿。底部预览不会执行真实行操作；点击“应用”才更新表格和本地设置。取消丢弃草稿；点关闭、点外部或按 Escape 关闭已修改的抽屉时会再次确认。恢复当前列、当前页、全部设置也先作用于草稿。

## 3. 列名称与样式

支持显示名称、表头和内容的独立字体/字号/颜色/字重/对齐、列宽、长文本省略/两行/完整换行、空值文案、表头说明和内容复制入口。项目名称下方的客户可以隐藏；金额支持 0/1/2 位显示小数及千分位；日期支持三种显示格式。

显示名称不改 `key`，也不改数据字段。列名不能为空、超过 30 字符或重名。金额显示位数只影响显示：原始金额仍以整数分保留，导出数值不按显示小数位截断。`0` 不按空值处理。

字体使用预设系统字体组合；字号 12–20px。字号/颜色等只接受受控配置，不接受 CSS 代码。表头对齐默认跟随内容；普通内容默认采用字段对齐。编号链接、状态和危险操作保留语义颜色，状态文字的字号与字重可以修改。浅色文字会显示对比度提醒；该提醒不等于整个页面已获得无障碍认证。

左侧勾选框用于**批量样式**，不是列显隐。选中多个列后，点击“应用到所选列”会把当前编辑列的表头和内容样式复制给它们，不复制名称、冻结和其他业务属性。显隐使用右侧的“显示此列”。

## 4. 数据排序

表头点击采用单字段三态：升序 → 降序 → 取消。点击表头选择单字段排序会替换现有组合排序；组合规则在“排序规则”中管理。

排序规则可添加、修改方向、拖动/上下调整优先级和删除。先筛选，再按全部规则排序，最后分页。金额按数值、日期按原始日期比较；空值始终放最后，同值保持原顺序。禁用某列排序会移除已应用的对应规则；选择框、序号和操作列不参与数据排序。

表头菜单的升序/降序会将对应列移到排序第一优先级，保留其他有效规则。“列的顺序”与“数据排序”是两项独立设置。

## 5. 操作列与二级菜单

默认行内：**查看、修改、更多**。更多中包含：复制为草稿、复制编号、导出本条、删除。导出本条展开 Excel/CSV 子菜单。

可配置每个已注册操作的显示位置（行内 / 更多 / 隐藏）、名称、显示形式、顺序、菜单分组与分隔线。支持统一或逐按钮选择文字、图标加文字、仅图标。删除名称固定为“删除”，保留危险色和确认。

可设置 0–4 个行内按钮、靠左/居中/靠右、常用间距。宽度不足时根据真实 DOM 宽度把末尾按钮收进更多，不按字符数量猜测。全部操作隐藏时不显示无内容的更多按钮。

开启分组时，更多菜单依次按普通、导出、危险分组，在组内保留配置顺序；关闭分组后按整体配置顺序显示。导出子菜单可调顺序或隐藏单项，全部子项关闭时导出入口隐藏。

菜单挂在表格外，避免被滚动区域裁切；打开末行菜单不会因为浏览器刚完成定位滚动而立即关闭。实际滚动表格时关闭菜单。菜单支持方向键、Home/End、Escape 返回；触屏用点击打开，不依赖悬停。

按钮配置只作用于代码已实现的操作，不创建自定义 JavaScript 或任意后台请求。本版没有虚构审批、合同等未实现业务。

## 6. 表格外观、视图和设置备份

外观包括统一字体、内容/表头字号颜色、行高、分页条数、边框、斑马纹、序号、悬停高亮。单列样式优先于统一设置。新增序号列会参与左侧冻结偏移计算；手机窄屏仍沿用横向滚动和解除冻结的策略。

命名视图保存已应用查询、完整列配置、组合排序、操作按钮、外观、行高和分页条数。修改命名视图后，点击“更新当前视图”覆盖，或“另存为视图”保存副本。默认视图在重新打开页面时恢复；“全部报价”清除筛选但保留当前表格布局。

“表格外观 → 导出设置 / 恢复设置”使用独立 JSON 文件，包含列、排序、操作和外观，不包含报价记录、选中的 ID 或查询文本。恢复先进入草稿，仍需点击应用。导出的内容是当前通过校验的草稿，未应用的合法修改也包含在内。

## 7. 数据导出

顶部“导出”提供真正的 `.xlsx` 与 CSV。范围包括全部查询结果、当前页、选中记录。更多菜单内可直接导出当前报价；行导出跟随当前可见业务字段、列名与支持的样式。

支持全部业务字段、可见列、自选字段与顺序、自定义列名、金额合计、查询条件和导出时间。项目客户副标题开启且采用可见列时，会补上独立客户字段。操作按钮、选择框和序号不进入导出。

Excel 中编号为文本、金额为数值、日期为日期序列并设置日期格式。可选择标准样式或当前字体/字号/颜色/字重/对齐及数字格式。状态标签导出为文字，按钮、链接交互和 CSS 特效不属于工作簿内容。支持的文字样式不等于完全复制网页像素排版。

Excel 附加说明在单独工作表。金额合计使用受控 SUM 公式并提供缓存值；超过设定精度阈值的大额合计改为精确文本并标明。用户输入永远作为文本单元格，不变成公式。

CSV 带 UTF-8 BOM，转义逗号、引号和换行，并处理危险公式开头文本。CSV 不保存文字样式；附加说明放在数据末尾，由用户明确勾选。CSV 的前导零等文本解释取决于使用的表格软件，导入时需要选择合适的字段类型；有文本类型要求时优先使用 XLSX。

可保存最多 20 个导出方案，包括格式、字段、顺序、列名/样式/合计/说明选项。方案不保存具体数据、选中的报价或某次导出范围。

### XLSX 实现边界

`xlsx.js` 是本项目专用的零依赖 OOXML/ZIP 写出模块，不是 ExcelJS，也不是通用 Excel 编辑器。支持多工作表、基础字体/填充/边框/对齐/数字格式、表头冻结、自动筛选、模板基础校验和受控 SUM；不支持任意公式、透视表、宏、图表、外部链接或读取现有 Excel。

ZIP 使用 STORE（不压缩），文件通常比压缩库生成的大。一次最多导出 10000 条；大规模正式业务建议改为服务端导出，保留 `export-data.js` 的字段和范围规则，并替换底层写出适配器。不要把本模块当成可读取任意外部工作簿的库。

## 8. 模板下载

顶部“模板下载”提供空白模板和带示例模板。二者使用固定字段，不受个人列名、隐藏、排序影响。

空白模板包括“数据填写”和“填写说明”，带示例模板另外添加独立“示例”工作表。预置 100 行填写样式，状态、大区列表及金额范围校验覆盖到第 10000 条；继续增加填写行时可复制已有空行格式。必填、长度、日期先后及两位小数规则写在说明里，不能把模板校验当作完整的入库校验。

本版**未实现 Excel 导入**。JSON 报价备份恢复、表格设置恢复与 Excel 导入是三个不同功能，不混用。

配置依赖从 `config → customization → core → UI/导出` 单向流动。字段 key 和行操作 id 稳定；显示别名不用于查询索引或接口映射。常规内容通过 DOM 文本节点或表单值输出，未使用 `eval` 或动态函数。富文本粘贴只在未挂载的 template 中解析 HTML，然后转换为受控文档并重新创建节点，不把输入 HTML 插入活动页面。

接入正式系统时，替换 repository 为 API 适配器，将偏好按用户/页面/版本存储；服务端独立验证权限、筛选、排序、导出字段及更新版本。前端隐藏、禁用或设置 JSON 不能承担授权责任。

## 12. 工具栏

分别配置页面工具栏和表格工具栏：名称、顺序、图标/文字/两者、直接显示/更多/隐藏、固定、分隔及间距。拖动和上下移动都可用。更多中的入口执行原功能，不是另做一个占位按钮。

默认保留旧排列；原“列设置”默认固定，320px 仍可直接打开。完整“表格设置”始终保留，不允许隐藏。用户可以自行决定其他按钮的位置。超过宽度时只收起非固定项，所有功能仍可从更多菜单访问。若用户把过多宽按钮都设为固定，仍需自行调整固定项，不能无限塞入窄屏。

默认工具栏按当前页面保存。选中“工具栏随命名视图保存和切换”后才随视图变化。隐藏/改名称不是权限，也不创建任意 JavaScript 或后台请求。

## 13. 列筛选与组合筛选

每列可配置是否允许筛选、文本/数字/日期/单选/多选、操作符、选项来源与顺序、搜索和数量展示。选择框、序号和操作列不参与。选项来源是完整本地数据、手动选项或映射字典；不是只取当前页。为避免一次渲染过多选项，显示最多 200 个候选并提示继续搜索，计数仍来自完整集合。

手动选项明确声明文本/数字/布尔类型。状态筛选显示映射名称，保存原始编码。顶部基础查询、列筛选和组合条件同时生效；同列多选是 OR，不同列为 AND。组合编辑器提供单组“全部满足/任意满足”，最多 30 条，暂不支持递归嵌套分组。

筛选在排序/分页、汇总和全部结果导出之前执行；顶上条件标签可独立移除，隐藏查询或隐藏列不会隐藏其有效条件。关闭列筛选或改成不兼容类型时，应用设置前确认移除受影响条件，不移除原顶部查询控件。

数字筛选使用当时显示单位，并把单位基数存入条件：之后将元改为万元或改变百分比显示方式，不会悄悄扩大/缩小已有筛选范围。默认范围和未来若干天等相对日期快捷方式本轮没有作为独立设置提供。

## 14. 值映射与数字格式

值映射支持文本、数字、布尔类型，原值→文字、标签或圆点，颜色、边框、图标、空值和未匹配兜底。相同原值不能重复；可按字典顺序排序。字符串 "01"、字符串 "1"、数字 1 不被错误混同。

原状态仍是 draft/review/contract；编辑的是显示规则，不是业务状态字典或数据库字段。本页可以把 draft 显示为“待处理”，但不会把已有状态改成数字 1。接入使用数字状态的后端时，需在字段/接口适配层明确数据类型和业务有效值。

原有金额小数位、千分位入口继续可用；新高级数字规则默认关闭，关闭后继续用原格式。开启后提供：普通数字、货币、百分比、固定/最多 0–8 位小数、千分位、单位缩放、前后缀、正负号/负数括号。当前数据中只有金额列是数值列；引擎不是自动把编号或文本猜成数字。

百分比必须选基数：比例值 0.1234→12.34%；百分数 12.34→12.34%。金额始终以整数分存储，先转元再按显示规则处理；增加显示小数位不创造新的存储精度。0 与空值分开；数字格式不修改原始金额。

试算可预览样例原值对应的文字与 Excel 数值/格式。预设提供常用格式和状态映射起点；预设先进入草稿，不立即改实际表格。

## 15. 富文本与列模板

本次交付的是**原生 Selection/Range 的轻量编辑器，不是 Quill**。原计划的第三方依赖无法在构建环境下载，因此采用本地实现，保留离线单文件。没有加载 CDN、在线字体或第三方编辑器运行时。该取舍不代表完整 Office/Word 编辑能力。

支持选中文字后设置字体、字号、粗体、斜体、下划线、删除线、文字/背景颜色；支持段落对齐、项目符号/编号列表、安全链接、清除格式及撤销/重做。中文输入合成时不切断录入。普通备注输入仍保留；在普通输入框继续改文字会提示并清除该备注的旧富文本格式，避免两个内容源不一致。

备注编辑器先回填表单，保存报价后才入仓库；编辑器取消不回填。备注纯文本上限仍为 1000 字，不因富文本放宽。内容超长时保留输入并禁止保存。记录同时保存 remark 纯文本与 remarkRich 结构化格式，复制、详情和 JSON 备份恢复保留；Excel/CSV 的备注采用纯文本。

列模板只改变整列的显示方式，可插入字段块并设置样式，最多 3000 字。字段通过白名单插入；不会执行字段中的 HTML，也不会递归执行其他字段的模板。启用空模板会被拒绝。原“项目＋客户”双行方式保留，模板关闭时回到旧显示。普通字段模板不自动改变结构化导出的字段列表。

保存与渲染只允许受控属性及 http/https/mailto 链接。粘贴先在未挂载 DOM 解析、再转换为白名单文档并生成全新节点；剔除脚本、图片、SVG、事件和危险链接。粘贴长度 200000 字符、节点 10000、层级 200 的资源上限用于拒绝过度内容，超限时保留原文。本版不支持图片、视频、文件、任意 HTML/CSS 或任意脚本。正式服务端接入仍需再次验证内容。

## 16. 数据工具（只读能力优先）

- **条件标记**：配置字段、比较条件、提示文字和颜色；最多 30 条，按顺序取首个匹配规则。标记只提醒，不修改业务状态。金额条件使用元，独立于显示缩放。
- **分组汇总**：客户、状态、负责人、大区，最多两层；完整查询结果分组，组内笔数和整数分合计。展开/收起及导出分组摘要；不替换原平铺表格和分页，不把组标题当记录删除。
- **记录对比**：选择 2–4 条当前查询范围记录，基准记录、只看差异、金额差额及导出。采用当前可见业务字段；整个面板只读。
- **区域选择**：先在数据工具中开启。鼠标框选或方向键/Shift 扩展当前页单元格，复制为行列文本；金额合计/平均/最小/最大使用原始整数分。复选框批量操作与单元格框选独立；不会因为框选而删除整行。查询、分页和重绘清空区域，防止复制过期内容。暂不提供整块粘贴修改或拖动填充。
- **设置历史**：保留最近 20 次完整设置应用、标记应用和恢复前的布局快照，显示差异后确认恢复。历史不含报价数据，不是业务审计或记录版本历史；不是每次拖动列宽都创建一条历史。原恢复默认、设置备份均保留。

这些功能是独立工具入口，不改变未开启时的日常写入流程。分组仍是前端只读报告，不是服务端大数据分组或性能承诺。

## 17. 导出、迁移与本轮边界
