## 3. 独立文件核验

用 Python ZIP/XML 检查实际下载内容，再由 artifact_tool 独立导入六份文件：

- browser-export.xlsx：编号为文本，金额为数值63860，日期为Excel序列。
- browser-template-blank.xlsx：固定字段，填写区无示例。
- browser-template-example.xlsx：独立示例工作表。
- rules-mapping-export.xlsx：显示值“待处理”和原值draft分别成列。
- rules-percent.xlsx：测试百分数12.34写为0.1234加百分比格式，原值列仍为12.34。
- rules-scaled.xlsx：金额缩放和总计单位一致。

前四份来自浏览器真实下载，后两份通过同一生产写出模块生成专用测试数据。普通导出和百分比文件完成独立渲染；这不等于用 Microsoft Excel/WPS 桌面打开。百分比测试数据不写回演示报价。

首次独立导入因 artifact_tool 守护进程启动超时失败，增加仅测试进程的启动等待上限后六份重跑通过。没有修改产品代码来规避该错误。

Node v22.16.0，Chromium 144.0.7559.96，Linux无头，Python Playwright。所有通过用例检查页面错误为空。

浏览器使用 set_content 装载完整 HTML；报价、表格、设置、菜单及导出均运行生产实现。持久化场景使用仅测试代码中的 Storage 适配器；“新文档恢复”不等于真实浏览器跨会话持久化。触屏/窄屏为模拟，不是手机真机。
