# 报价管理表格自定义 · 已确认范围

以 quotation-refactor-icons.zip（1.0.1）为基线，按本次对话中已确认的方案实现。
继续提供原生 JavaScript / CSS 分文件源码和同源构建的离线完整 HTML。业务数据字段、数据仓库和原有增删改查保留。

## 配置与显示
- 快捷列面板保留左右冻结图标，增加更多设置入口。完整设置用右侧抽屉，包含列、排序、操作、外观四页，修改仅在预览生效，应用后更新表格。
- 列可重命名（1–30 字，避免重名，仅显示别名），独立表头/内容字体、字号、颜色、字重、对齐。白名单字体和六位十六进制颜色，不接受 CSS/脚本。
- 列宽、单行/两行/完整换行、空值、金额和日期显示格式、复制内容、表头说明、客户副标题、排序开关。编号保持显示。
- 多列样式批量应用，恢复当前列/当前页/全部配置，斑马纹/边框/序号/悬停高亮。
- 排序区分列位置和数据排序。多字段排序从上到下优先，空值最后，稳定排序，先排序后分页。单表头仍三态。

## 操作
注册操作白名单：查看、修改、复制为草稿、复制编号、导出本条、删除。默认行内查看/修改，其余更多。
可重排、隐藏、改变行内/更多、设置展示形式和间距/对齐/行内数量。导出本条允许 Excel/CSV 子菜单及顺序。删除保留原名称、危险色与确认。按钮配置不是权限系统。
菜单挂载到表格外，避免被裁切；支持点击、方向键、Escape、回焦点。宽度不足收进更多，不换行。

## 导出
使用原生 OOXML/ZIP 写出模块，支持本项目的单元格类型、样式、冻结行、筛选和模板校验；离线 HTML 内嵌，无 CDN。
导出 Excel/CSV，范围为查询结果/当前页/所选/单条；可见/全部/自选列，重排，别名或标准名，Excel 可应用字体/对齐样式，附加合计/条件/导出时间。导出方案本地保存。
CSV 防公式注入。Excel 文本明确为字符串、金额数值、日期真实日期；超出 Excel 精度范围的汇总使用精确文本并提示。
空白与带示例的固定字段 Excel 模板（填写区、说明、可选示例），不受个人列设置影响，不包含 Excel 导入流程。

## 持久化与兼容
表格配置 schemaVersion=2；读取旧版列宽/冻结/可见和单字段 sort，迁移为多字段 sorts。业务数据 schemaVersion 不变。
视图快照保存新增设置；设置备份仅含展示配置，不混入报价数据。恢复先进入草稿，确认应用。
存储失败时不误报持久化成功。保留数据版本冲突保护。最大 10000 条演示数据；不新增后端认证/审批/合同。
