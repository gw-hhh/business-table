# 更新记录

## 3.1.0 · 2026-09-21

在 3.0 完整源码上作体验精修，未替换为早期原型。保留业务数据、schema 3 配置、左右冻结图标及原有查询、写入、导出和数据工具。

- 默认字体/间距/控件高度/辅助文字对比度统一；紧凑、默认、宽松仍可选择。用户自定义样式不重置。
- 工具栏设置采用共享表头的紧凑列表，窄屏显式分行；映射规则突出原值到显示值，样式可展开。
- 设置固定当前编辑对象与修改摘要；批量样式和列显隐分开表达；切换列和分类恢复本次滚动位置。
- 新增当前对象/整表预览、样例选择与折叠记忆；预览表格复用正式渲染，预览动作无业务副作用。
- 对齐分段、字体搜索、常用色板、小数精度快捷选择；所有原有细调能力保留。
- 富文本工具分组、选区混合格式、编辑区展开、明确“回填备注”；原普通备注输入和格式能力保留。
- 修复表头图标悬停挤压、设置目标重复滚动留白、快捷列草稿基线、批量样式无变化判定、试算与预览不同步等问题。

验证命令、真实结果和未覆盖环境见 `docs/TEST-REPORT.md`。本轮仍不加入 Excel 导入、正式权限、审批或后台任务。

## 3.0.0 · 2026-09-20

以 2.0.0 完整代码为基线，保留全部原模块、事件入口、业务校验和测试断言。

新增：工具栏编排、每列筛选、组合条件、类型化值映射、数字/百分比格式、格式试算、结构化富文本备注、字段显示模板、条件标记、分组汇总、记录对比、区域选择与统计、设置历史、显示/原值导出及导出预览。

配置 schema 升级为 3，旧 schema 2 可读取；报价存储键和原始状态/金额模型保持不变。

修正：金额相等筛选精度、数字筛选单位快照、富文本重复染色、裸文本对齐/列表、危险/深层粘贴、禁用筛选前确认、设置恢复的条件清理时机、窄屏快捷列入口、提示关闭按钮挡住自定义工具。

编辑器为原生轻量实现，不是 Quill；不增加 Excel 导入或服务端业务流程。详细行为与限制见 README 和 docs/TEST-REPORT.md。
