## 迁移原则

1. 不机械翻译旧 JavaScript。
2. 不删除旧版已有能力。
3. 旧版作为产品行为和视觉参考；新 Vue 架构作为实现约束。
4. 每个迁移项先补测试，确认 RED 后实现。
5. 每批完成后更新本矩阵。
6. feature → development；development Release Gate 全绿后才能 main。
