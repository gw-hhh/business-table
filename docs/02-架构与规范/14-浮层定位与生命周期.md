# 浮层定位与生命周期

所有默认锚定浮层通过 [useFloatingPosition](../../src/ui/useFloatingPosition.ts) 使用 `@floating-ui/vue` 的定位引擎与中间件。公共层负责定位、尺寸与观察器；组件继续负责打开状态、权限、键盘、外部点击关闭和业务动作。持久化格式不变，新增可选滚动策略和受控显示契约。

## 定位契约

- `anchor`、`popup` 和 `open` 接受响应式值。DOM 尚未挂载或已关闭时不建立观察器，首次定位完成前隐藏浮层，避免闪到左上角。
- 固定定位依次使用 `offset`、`flip`、`shift`、`size`：保留入口间距，空间不足时翻转，约束到可用边界，超高内容由浮层内部滚动。默认边界为视口；色板显式限制在设置内容区。
- 使用 `left/top` 输出位置，保留现有 CSS 动效；共享层设置 `max-width`、`max-height` 和 `--bt-floating-max-height`。行操作保留外层可见溢出，让固定定位的子菜单不受内部滚动列表裁剪。
- `autoUpdate` 跟踪滚动、尺寸和布局变化；自定义容器另由 ResizeObserver 跟踪尺寸，覆盖入口没有移动但容器缩小的情况。每次更换元素、关闭或卸载都会清理监听与观察器；会话和请求序号阻止过期异步结果覆盖新浮层。
- `onPositioned` 在坐标与可见样式提交后执行，每次打开只调用一次。菜单在此时设置初始焦点；普通尺寸更新不夺取用户焦点。
- 定位拒绝时清理观察器并隐藏浮层，通过 error 状态与 onError 回调交还组件；组件关闭当前浮层，已有错误/通知通道继续报告。旧请求失败同样受失效检查约束，不覆盖新会话，不使用猜测坐标兜底。

## 各组件行为

| 组件 | 入口与边界 | 滚动与关闭 |
| --- | --- | --- |
| AnchoredPopup | 入口右下方，视口内避让；保留宽度参数 | 外部滚动关闭；自身及注册的子浮层滚动保持；窗口变化重新定位 |
| 行操作与递归子菜单 | 主菜单入口右下，子菜单右侧优先、必要时向左 | 外部滚动或窗口变化关闭主菜单；父列表真正滚动时关闭其子菜单 |
| ToolStrip 更多工具 | 入口右下，视口边距 12px | 跟随滚动与尺寸变化；子菜单沿用 popupScope，内部点击不误关闭父菜单 |
| ViewsPanel | 入口左下，视口内避让 | 跟随入口、滚动与窗口变化；Escape 恢复入口焦点 |
| ColorSelect | 色板入口右下，设置内容区内避让 | 外部滚动或窗口变化关闭；选择颜色或 Escape 后恢复入口焦点 |

键盘导航、Tab 离开、权限执行前复查和嵌套 Escape 的语义由现有组件保留。定位层不保存业务状态，也不接管 PopupScope、对话框焦点约束或排序逻辑。

## 滚动策略和退出动效

共享定位支持 `scrollStrategy: 'close' | 'follow'`；AnchoredPopup、ActionStrip、ColorSelect 默认 close，ToolStrip、ViewsPanel 默认 follow，公开 TableTools 可传同名属性。内部及注册子浮层滚动保持；锚点移除/定位失败仍会关闭。跟随策略不取消原有权限、外部点击和 Escape 规则。

DialogFrame/AnchoredPopup 的 `open` 默认 true。需要退出动画时持续挂载组件并传 `:open`，Vue Transition 管理实际节点，共享 useMotion 负责可取消的动画。对话框离场时不可操作，滚动锁/焦点在离场完成后释放；父页面卸载立即清理。FeatureHost 的 deferClose 契约用于设置、筛选和数据工具的默认弹层；每次重新打开创建独立 UI 会话，取消的草稿不会因快速重开复活。不要在卸载后克隆或重新挂接旧 DOM。系统减少动态效果开启时直接完成，运行中切换也结束动画。

搜索区 `searchPanel.animateCollapse: true` 复用同一生命周期，SearchRegion 切换为 block 包装；默认仍使用 display:contents，避免改变已有自定义网格布局。收起期间保留草稿并将不可见表单设为 inert。

## 验证范围

[组件定位测试](../../tests/floating-position.spec.ts)使用真实 Floating UI 引擎与可控 DOM 几何，覆盖入口替换、内容增高、自定义容器缩小和卸载后的观察器清理；现有行操作、工具菜单、视图测试继续检查键盘、权限与视口约束。[浏览器用例](../../tests/e2e/floating-ui.spec.ts)验证真实布局中的入口移动、窄视口、重开、滚动关闭、子菜单点击区域和色板容器边界。实际结果以本批验收记录为准；单测不替代浏览器视觉验收。

定位依赖的 API 说明见 [Floating UI Vue](https://floating-ui.com/docs/vue)、[autoUpdate](https://floating-ui.com/docs/autoupdate) 与 [size](https://floating-ui.com/docs/size)。
