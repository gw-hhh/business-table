# 界面与交互规范

BusinessTable 是通用表格平台。报价页的产品、布局和交互以[旧版页面](../../reference/legacy-v3.1/quotation-manager-v3.1/index.html)为参照，正式实现由 Vue 组件、Feature 和 Runtime 承担；其他业务按同一交互规则接入，无须照搬报价页面。能力归属见[平台总体设计](01-平台总体设计.md)，开关和权限见[配置与能力规范](03-配置与能力规范.md)。

## 页面层级与尺寸

- 按页面标题及操作、查询、视图及表格工具、条件反馈、表体、汇总分页组织内容。业务页决定页面排版，表格提供相应区域和插槽；没有启用的能力不占位。
- 默认正文约 14px，辅助文字 12–13px，常规控件约 32–36px。沿用当前蓝色主操作、浅色背景和清晰的边框层级；新增文案短、直接，保留已有业务文案。
- 表格支持紧凑、默认、宽松三档密度。双行单元格和增大字号时允许内容撑开，不能以固定行高裁掉文字。容器余量分配只改变渲染宽度，不能改写用户保存的列宽；用户主动调宽走列配置修改入口。
- 窄容器中普通表单不产生页面横向溢出，宽表在表格内部滚动。表头、左右冻结列和分页需在滚动及改变容器宽度后保持对应；下拉菜单在视口内定位，超高内容自身滚动。

- 设置抽屉桌面最大宽度 920px，常规表单控件高 32px，分组间距 12px，工具配置行约 42px；窄屏自动换行并显示固定／分隔标签，不挤压控件产生页面横向滚动。
- 有明确连续范围的设置采用常显滑条＋数字输入：表格及单列字号 10–32px、按钮间距 0–32px、工具间距 0–24px、行内按钮 0–4 个、小数位 0–8，列宽沿用各列约束。字号／间距／数量按整数步进，列宽保留既有合法精度；滑条和数字输入共用草稿，键盘方向键、Home／End 可调整。每页条数、行高、倍率等离散选项继续使用选择控件。
- 单列字号明确区分“跟随表格”和显式数值，拖动后成为单列覆盖，“跟随表格”清除覆盖。数字越界、空输入或非法步长保留输入并阻止应用，切列／切页签保留错误，恢复按列、文字组或当前页清理对应范围。数值缓冲属于设置会话，不进入配置、View 或 Persistence。

- 分组标题右侧依次放次要操作与折叠按钮，恢复不抢占最后位置。列标题下用字段类型和带绿色圆点的显示状态构成辅助行，恢复此列放该行右侧；隐藏状态用灰点并保留文字。
- 滑条旁保留数值和单位；正常状态不重复展示上下限，越界时显示具体范围错误。继承字号仍可看出是否跟随表格。
- 操作按钮采用与工具栏一致的紧凑可编辑列表；整组和二级菜单可折叠。窄屏换行后不产生横向溢出。条件标记的字段/条件/值与文字/颜色分行对齐，结果标签只显示文字。共享筛选编辑器的样式由组件自身引入，不能依赖另一 Feature 已打开。
- 视图有未保存的修改时显示浅黄色小圆点，保留无障碍名称和悬停说明；不再增加可见“未保存”文字或视图旁条数。保存成功或恢复一致快照后去掉圆点。
- 表格外观不再提供设置备份导入/导出。偏好、视图持久化和业务数据备份属于独立能力。

## 状态与操作

设置字段按内容用途分配空间：短枚举约 128px、普通字段约 180px、滑条约 230–300px、颜色组合约 260px，名称/说明/原始值可伸展；这些是内部布局尺寸，不是公共配置。共享 `bt-settings-form` 按父容器可用宽度换行，不用桌面平均分栏强迫短选项铺满；长日期、布尔口径保留足够可读宽度。窄屏保持原字体和可访问标签，不通过缩小字号容纳更多控件。

- 搜索区域的整体显示/隐藏与高级条件展开分别管理，隐藏保留挂载表单及未提交草稿；开关通过唯一 aria-controls 关联 SearchRegion。默认手动查询，可显式启用防抖自动提交。独立搜索、表体与分页共用一个 Runtime；分页栏隐藏仍按页查询，关闭分页须读取完整受限结果，详见[组件组合与分页](12-组件组合与分页.md)。
- 查询草稿与已应用条件分开。修改字段提示待查询，提交后更新结果；条件标签显示已应用值。隐藏查询区不清除条件，查询区控件偏好独立保存；命名视图也可保存并恢复折叠快照。基础查询与列筛选、组合筛选共同作用，但编辑面板的取消不改正式查询。
- 快捷列面板和完整设置抽屉使用同一草稿。预览只读取草稿；确认或应用才修改正式表，取消丢弃。关闭时直接取消未应用修改，仅显示短暂提示，不要求确认；应用校验错误保留输入并定位到对应项。设置应用不等于保存当前命名视图。
- 设置项有隐藏、可编辑、显示但只读三种结果：未声明或关闭即隐藏；显式开启可编辑；显式 `disabled` 才显示只读。设置页、列模块、列能力取交集，远端只能收窄。只读项不能通过自定义界面、Headless 命令、恢复或重置绕过守卫；已有合法值仍可显示。
- 列编辑标题、恢复此列和模块导航在独立固定区域，下方设置内容单独滚动；切换模块先展开目标，再定位内容。基本、文字样式、内容、筛选、映射、数字、模板、试算及其他设置分组共用折叠组件，默认收起，展开按钮及箭头使用蓝色；预览也默认收起。收起只隐藏表单，不卸载输入或清除草稿。折叠属于当前设置会话的界面状态，不写入业务配置或命名视图；只读内容仍可展开查看。
- 冻结列使用左、右两个直接图标，点击已选侧取消。拖动排序须有键盘上下移动入口；所有已有排序列表共用拖动指示，鼠标位于目标上半行或下半行时分别显示前插或后插蓝线，松开才调用原有排序命令。自身、相邻不变位置、外部拖动及不可移动项不显示有效插入线；取消或离开目标后清除提示。页面／表格工具分组独立，工具和操作使用稳定 ID，隐藏的工具仍可在设置中重新开启，有权限限制的动作在点击时重新检查。
- 筛选候选项以原值查询和保存，以标签展示。数字 `1`、文本 `"1"`、布尔值和空值不混同；远端标签缺失时显示原值，不篡改条件。金额和百分比筛选保存输入时的单位基准，修改显示格式后命中范围不漂移。

## 键盘、焦点与动效

- 按钮、标签页、菜单和对话框提供可见焦点。菜单支持方向键、Home/End 和 Escape；对话框约束 Tab，关闭后将焦点还给入口。嵌套弹窗只关闭最上层，输入法组合期间不触发快捷键。
- 非输入区的 `/` 可由宿主定位查询输入框；查询区隐藏时先显示再聚焦。禁用项可见但不可触发；操作执行前再次检查当前可用性。
- 弹窗和提示使用短暂、克制的过渡；`prefers-reduced-motion` 下停止非必要动画。滚动位置、焦点和未应用草稿应在切换列、页签或打开子弹窗后保持可预期。

实际实现可从 [DialogFrame](../../src/ui/DialogFrame.vue)、[设置抽屉](../../src/components/ColumnSettingsDrawer.vue)、[查询组件](../../src/components/TableSearch.vue)和[表格滚动适配](../../src/presentation/useTableViewport.ts)核对。视觉验收须在浏览器中与旧版实际页面对照；测试要求见[测试与验收规范](06-测试与验收规范.md)。

共享交互底层分别见[富文本编辑器接入](13-富文本编辑器接入.md)、[浮层定位与生命周期](14-浮层定位与生命周期.md)和[拖动排序与权限](15-拖动排序与权限.md)。编辑状态、拖动影像和浮层坐标只属于当前组件会话；RichDocument、业务排序命令和原有配置协议保持职责边界。
