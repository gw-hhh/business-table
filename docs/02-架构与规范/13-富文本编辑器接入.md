# 富文本编辑器接入

共享 `RichEditor.vue` 使用 Tiptap 3 的 Vue 编辑视图和 ProseMirror 事务、选区及撤销历史。备注与列模板继续保存 `RichDocument` 的 `ops`，无须迁移已有数据。表格单元格、详情只读展示和导出继续使用原有安全读取、VNode 渲染与纯文本解释；每个单元格不会创建编辑器实例。

## 边界与加载

编辑实现位于 `src/features/rich-text/`。业务页面只提供文档、字段和保存动作；模板引用始终使用 `column.id`，显示名称随列标题更新。报价备注和列设置模板在打开编辑弹层时通过 `defineAsyncComponent` 加载编辑器，关闭后销毁编辑器实例及字段节点监听。

`tiptap-document.ts` 在持久化文档与编辑器 JSON 之间转换，`tiptap-extensions.ts` 声明可保存的节点与样式，`clipboard.ts` 解析脱离页面的剪贴板 HTML。Tiptap JSON、ProseMirror 选区与历史不进入 Preference、View 或业务记录，也不是公开持久化协议。

## 现有组件契约

| 参数 / 事件 / 方法 | 约定 |
| --- | --- |
| `modelValue` / `update:modelValue` | 读写 `RichDocument`；仅发送实际变化后的安全文档。 |
| `label` | 默认“富文本编辑”，用作编辑区及工具栏无障碍名称。 |
| `template` / `columns` | 模板模式可插入字段，隐藏链接工具；字段只接受已注册稳定 ID，操作列不出现在插入菜单。 |
| `maxChars` | 默认 1000；模板调用方沿用 3000。按 Unicode 码点计数，字段占一个字符，末尾结构换行不计入显示计数。 |
| `readonly` | 隐藏工具栏并关闭内容编辑。 |
| `expand` | 保留展开事件，由宿主决定打开方式。 |
| `focus()` / `getDocument()` / `getSelection()` | 保留已有实例方法。文档返回独立副本；选区采用 UTF-16 文本偏移，字段占一个单位。 |

宿主回写本次 `update:modelValue` 不会重建编辑器。外部替换为不同文档时重建编辑状态并清空撤销历史，避免撤销恢复另一条记录。不同编辑器各自管理临时状态和历史。

## 支持格式与兼容处理

支持粗体、斜体、下划线、删除线、受限字体令牌及字号、六位十六进制文字和背景颜色、左／中／右对齐、单层有序／无序列表、普通备注链接及模板字段。段落对齐与列表类型继续保存在换行操作属性上。相邻相同格式文本可能合并为一个操作，显示、字段和属性语义保持一致。

StarterKit 中不能用现有协议表达的标题、代码、引用块、分隔线关闭；列表项 schema 限制为段落，不提供嵌套列表。Markdown 自动输入规则与自动粘贴规则关闭，避免出现工具栏之外的隐式格式。字段使用不可拆分的行内原子节点，删除和撤销都保留完整字段 ID。

粘贴的 HTML 先经过既有白名单解析，再生成 Tiptap 内容。脚本、图片、嵌入对象、任意 CSS 和事件属性不会写入编辑器。链接仅接受不含凭据的 `http`、`https` 和 `mailto` 地址；模板模式移除链接。剪贴板声明的未知字段不会成为有效字段节点。

超长输入完成后裁掉超出部分并显示原有提示；截断不会切断 UTF-16 代理对。中文组合输入过程中暂缓提交与长度裁剪，组合结束后再统一处理。编辑器内拖入文件或外部 HTML 不受支持。

## 验证与边界

`tests/tiptap-rich-document.spec.ts` 覆盖真实 ProseMirror 事务、格式与列表、原子字段、长度、撤销重做及旧文档转换；`tests/tiptap-rich-editor.spec.ts` 覆盖组件契约、DOM 输入、动态标题、外部替换和模拟中文组合事件。`tests/full-rich-editor.spec.ts` 保留恶意剪贴板与字段白名单测试。浏览器场景见 `tests/e2e/tiptap-editor.spec.ts`，由完整发布门禁同时运行开发页面与生产预览。

模拟组合事件只能验证组合期间的处理边界，不能代替 Windows 中文输入法候选窗口、长句转换、选词后回退及移动端输入法的人工验收。真实输入法和用户视觉体验需单独确认；本批实际执行结果以验收记录为准。
