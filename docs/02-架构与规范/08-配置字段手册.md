# 配置字段手册

本手册对应当前公开接口，用于查字段、范围和相互关系。规则事实源为[配置与能力规范](03-配置与能力规范.md)，完整可编译文件见[接入示例](../03-业务模块/01-接入示例/README.md)。总体设计中的未来接口不自动成为可用配置。

## 配置放在哪里

| 内容 | BusinessTable | ConfiguredBusinessTable |
| --- | --- | --- |
| 表格标识与字段 | `tableKey`、`rowKey`、`columns` | `definition.tableKey/rowKey/columns` |
| 初始分页 | `pagination` | `definition.pagination` |
| 功能开关 | `features`，远端 `remoteFeatures` | `definition.features`，远端 `remoteOverride.features` |
| 搜索定义 | `searchDefinition` | `definition.search` |
| 搜索区域显示与自动提交 | `searchPanel` | `definition.searchPanel` |
| 搜索区域偏好存储 | `searchPanelPersistence` | 相同 |
| 设置页与列模块 | `settingsDefinition`、`settingsOverride` | `definition.settings`、`remoteOverride.settings` |
| 外观/动作/工具布局 | `presentation` | `definition.presentation` |
| 数据工具定义 | 四个同名属性 | `definition` 下四个同名字段 |
| 数据 | `data` 或 `dataSource` | 相同 |
| 真实工具 | `tools: { page, table }` | 相同 |
| 行操作 | `actions` | `registry` + `features.rowActions.details.allowedItems` |
| 命名视图输入 | `views` | 相同；管理见[视图指南](10-偏好与视图持久化.md#命名视图) |
| 筛选方案存储 | `filterPlanPersistence` | 相同 |
| 统一条件摘要 | `querySummary` | 相同 |
| 偏好输入/写入 | `config` / `persistence` | `preference` / `savePreference` |

配置入口 `definition` 必须有 `schemaVersion: 3`、非空稳定 `tableKey` 和 `columns`。它不是任意透传包装器；例如选择、填充高度以及完整表格引用方法应使用直接入口，不应推测配置入口具有所有相同方法。

## 表格基础属性

| 字段 | 类型/默认 | 用法 |
| --- | --- | --- |
| `rowKey` | string，`id` | 业务主键字段；不要用当前页下标作行键 |
| `tableKey` | string，直接入口默认空 | 持久化必须非空并隔离账号/页面 |
| `data` | 行数组，默认空 | 完整本地数据，与 DataSource 二选一 |
| `dataSource` | `DataSource<T>` | 后台分页、查询、完整读取和选项协议 |
| `pagination.pageSize` | 正整数 | 应选在 pageSizeOptions 内；不使用滑条输入任意页大小 |
| `pagination.pageSizeOptions` | number[] | 控制合法每页条数；外观中的页大小也受其约束 |
| `selection` | boolean，直接入口可选 | 业务行勾选，与区域选择分开 |
| `fill` | boolean，直接入口可选 | 填充已确定高度的父容器，内部滚动 |
| `density` | compact/default/comfortable | 直接入口基准密度，也可在 presentation 中指定 |
| `loading` | boolean | 宿主额外加载状态；组件自身维护查询 loading |
| `preferenceTimeoutMs` | 直接入口默认 3000 | 初始偏好读取等待时限，单位毫秒；不是业务查询超时 |

基础 props、事件和类型见 [types.ts](../../src/types.ts)、[BusinessTable.vue](../../src/BusinessTable.vue) 与[配置包装器](../../src/ConfiguredBusinessTable.vue)。

### 分页行为和外观

以下字段位于直接入口 `pagination` 或配置入口 `definition.pagination`，也可传给公共 `useTableRuntime`。`total` 由查询结果计算，不从 pagination.total 取外部总数。

| 字段 | 默认/范围 | 行为 |
| --- | --- | --- |
| `page` | 正整数，默认 1 | 初始页码及后续属性更新，超出结果范围时纠正 |
| `enabled` | true | false 关闭分页；本地返回完整筛选结果，远程要求 readAll |
| `visible` | true | false 隐藏分页栏，仍按页查询 |
| `hideOnSinglePage` | false | true 时仅一页不显示分页栏 |
| `showTotal` / `showPageSize` | true | 总数区域 / 页大小选项 |
| `showPageNumbers` / `showJumper` | 跟随 variant | 显式 true/false 优先；full 默认显示，simple 默认隐藏 |
| `align` | right | left/center/right，分页控件对齐 |
| `variant` | simple/full | 独立分页默认 simple；BusinessTable 的 fill 模式默认 full |
| `unpagedLimit` | 1–10000，默认 10000 | 远程关闭分页时的完整结果上限；适配器不得静默截断 |

直接入口 pageSize 默认 20，pageSizeOptions 默认 `[10,20,50,100]`；配置入口默认 `[20,50,100]`。非法选项过滤并去重，页大小不在允许列表时使用合法回退。配置入口对新字段校验并发诊断；运行时关闭分页后页码为 1。完整组合、插槽和失败契约见[组件组合与分页](12-组件组合与分页.md)。

### 搜索区域

| `SearchPanelOptions` | 默认/范围 | 行为 |
| --- | --- | --- |
| `regionId` | 自动生成唯一 ID | 自定义时自行保证页面内唯一 |
| `defaultVisible` | true | 初始化查询区域显示状态 |
| `toggleButton` | false | 是否绘制 BusinessTable 内置显示/隐藏开关 |
| `autoSubmitMs` | 未声明 | 可选 0–10000 毫秒防抖；超过上限按 10000，负数或非有限值不启用 |

`searchPanelPersistence` 为同步 `load(tableKey)`、`save(tableKey,{searchVisible,advanced})`；空值使用默认，非空值需有两个 boolean 字段，可传 JSON 文本。失败走 diagnostic。区域显隐保留搜索草稿，高级条件展开独立；不写入 Query/Preference/View。SearchToggle 与 SearchRegion 共用 `runtime.searchPanel`，`runtime.searchContext()` 提供字段草稿和提交命令。

### 公共组合入口

`@company/business-table/runtime` 导出 `useTableRuntime`、`TableRuntimeInput/Events/Runtime` 等状态 API；`@company/business-table/components` 提供 BusinessTableGrid、SearchRegion、SearchToggle、TableSearch、TablePagination 和 TableTools。TableTools 沿用 tools/layout，业务 handler 显式调用 Runtime；Grid 不自动创建完整 BusinessTable 的高级 Feature 面板。完整参数、样式和实际包示例见[组件组合](12-组件组合与分页.md)。

## Feature 开关

`TableFeatures` 当前包含：`title`、`search`、`views`、`toolbar`、`columnSettings`、`rowActions`、`filters`、`conditionalFormatting`、`grouping`、`compare`、`rangeSelection`。

| 写法 | 结果 |
| --- | --- |
| `false` 或未声明 | 关闭；兼容例外：直接入口显式传 title/views/actions 会作为对应功能的本地声明 |
| `true` | 开启，使用默认界面 |
| `{ enabled: true, mode: 'custom' }` | 使用对应 slot 提供界面，复用上下文 |
| `{ enabled: true, mode: 'headless' }` | 不绘制该功能默认界面，宿主使用上下文 |
| `{ enabled: true, entry: false }` | 隐藏默认入口按钮，保留命令和上下文入口 |
| 四项数据工具中的 `{ enabled: true, disabled: true }` | 保留可查看结果，拦截编辑；区域选择不能启动 |

通用 Feature 声明没有统一的 `disabled` 字段。设置只读写在 SettingsDefinition/ColumnCapabilities，行动只读写在 Action，四项数据工具另有 disabled。不要把 `disabled` 随意加到任意 Feature 然后期待生效。

`details.label` 可覆盖入口文字；`details.allowedItems` 表示稳定 ID 白名单，含义由功能决定（行操作为动作 ID，Search 为搜索项 ID，Filters/数据工具为列 ID）。远端只能在本地已开放范围内收窄，不能注册 handler、增加列或开启本地关闭能力。

`loadStrategy` 支持 eager/after-definition/on-visible/on-interaction；默认列设置、筛选和数据工具按交互加载，views 在定义后，其他为 eager。关闭功能先短路，再决定是否读详情与加载。按需功能通过 `activateFeature` 激活后再取上下文。

## 设置显示与只读

设置能力为三层交集：**pages.columns → columnSections → 该列 configurable**。其他设置页由相应 pages 控制；是否有可用内容还取决于实际列和动作/工具声明。

| `ControlConfig` | 显示 | 可编辑 |
| --- | --- | --- |
| 未声明 / false / `{ enabled: false }` | 否 | 否 |
| `{ enabled: true, visible: false }` | 否 | 否 |
| true / `{ enabled: true }` | 是 | 是 |
| `{ enabled: true, disabled: true }` | 是 | 否 |

只读保留已有合法值，限制后续修改；未声明不代表默认只读。只读父级会使可见子项只读。远端只收窄，默认 UI、Custom、Headless 和恢复备份都受相同写入守卫限制。

### 设置页和列模块

| 配置 | 界面 | 对应列能力 |
| --- | --- | --- |
| `pages.columns` | 列设置 | 以下 columnSections 的父级 |
| `pages.sorts` | 排序规则 | 多字段排序编辑 |
| `pages.actions` | 操作按钮 | presentation.rowActions，需实际动作 |
| `pages.appearance` | 表格外观 | presentation.appearance |
| `pages.toolbar` | 工具栏 | presentation.toolbar，需实际工具 |
| `columnSections.basic` | 基本 | rename/visible/order/width/fixed/align/sortable/headerStyle/cellStyle |
| `columnSections.content` | 内容 | content |
| `columnSections.number` | 数字 | format；仅 number/currency/percent 列 |
| `columnSections.filter` | 筛选 | filter |
| `columnSections.mapping` | 映射 | mapping |
| `columnSections.template` | 模板 | template |
| `columnSections.trial` | 试算 | trial，仅显示与导出预览 |

注意模块键是 `number`，对应能力键是 `format`；字段标题可修改的能力键是 `rename`，不是 `title`。

## ColumnConfig 与 ColumnDefinition

| 字段 | 可用值/用途 |
| --- | --- |
| `id` / `field` / `title` | 稳定列 ID / 行数据字段（支持路径）/ 显示标题 |
| `type` | text / number / currency / percent / date / enum / boolean |
| `kind` | data 或 actions；操作列不参与普通筛选及数据导出 |
| `width` / `minWidth` / `grow` | 基准宽度 / 最小宽度 / 剩余空间分配权重 |
| `visible` / `fixed` | 显示布尔值 / left、right、false |
| `align` / `sortable` / `filterable` | left、center、right / 排序开关 / 筛选开关 |
| `headerStyle` / `cellStyle` | 字体 token、字号、字重、文字颜色、对齐 |
| `content` | 省略/两行/换行、空值、辅助字段、复制、链接及日期格式 |
| `numberFormat` / `numberRule` | 基础数字格式 / 带 enabled、scale、sign 的数字规则 |
| `valueMap` / `mapping` | 简单 value/label 映射 / 标签、圆点、颜色和空值等扩展规则 |
| `filter` | 列筛选编辑器、来源、操作符与候选项 |
| `template` | `{ enabled, document: { ops } }`，受约束富文本数据 |
| `renderer` | 代码 Registry 中的 renderer ID |
| `configurable` | 控制个人可编辑哪些设置；不代表字段本身是否输出 |
| Definition 独有 `access` | false 时排除该列；不能替代服务端数据权限 |
| Definition 独有 `default` | 代码给出的 `UserColumnConfig` 默认覆盖 |

`configurable.width` 可以是 true，或 `{ enabled: true, min: 120, max: 480 }`；`configurable.fixed` 可用 `{ enabled: true, allowedValues: [false, 'left'] }` 限制冻结侧。固定业务列可在默认值设 `visible: true, fixed: 'left'` 并不开放相应修改能力。

### 内容、数字与映射

| 配置 | 值与说明 |
| --- | --- |
| `content.wrap` | ellipsis / two / wrap |
| `content.dateFormat` | iso / slash / cn；不是任意日期格式表达式 |
| `content.secondaryField/showSecondary` | 辅助字段路径与开关 |
| `content.copyable/link` | 复制/打开交互；打开后业务导航由 cellAction 处理 |
| `numberRule.style` | decimal / currency / percent |
| `numberRule.scale` | 1 / 1000 / 10000 / 100000000，只影响显示解释 |
| `numberRule.percentBase` | ratio：0.1234 → 12.34%；percent：12.34 → 12.34% |
| `numberRule.sign` | auto / always / accounting |
| `numberRule.minimumFractionDigits/maximumFractionDigits` | 最小不得大于最大；设置 UI 0–8，底层兼容 Schema 0–20 |
| `mapping.type` | text / number / boolean；原值类型不混同 |
| `mapping.presentation` | text / tag / dot |
| `mapping.empty/unknown/items` | 空值、未匹配显示及规则数组；不是查询值转换 |

数字、映射和模板最终由共享列解释器处理。复杂配置建议逐项开启，在试算中核对原值、显示文本、导出值和 Excel 格式，不同时设置两套互相矛盾的规则。完整原值/显示值示例见[配方](11-场景配置配方.md#数字原值与显示标签)。

## Presentation：范围、默认值和布局

以下为共享基础默认值；业务 definition、已有 Preference/View 可覆盖。非法字段按白名单拒绝，不推测成别的值。

| 字段 | 默认 | 合法范围/值 |
| --- | --- | --- |
| appearance.fontSize / headerFontSize | 14 / 14 | 整数 10–32 px |
| appearance.fontFamily | system | inherit/sans-serif/serif/monospace/system/yahei/pingfang/simsun/mono |
| appearance.color / headerColor | #334155 | 六位十六进制颜色 |
| appearance.density | default | compact/default/comfortable |
| appearance.border | horizontal | horizontal/full/none |
| appearance.stripe / index / hover | false/false/true | boolean |
| appearance.pageSize | 10 | Schema 正整数至 1000，最终受 pageSizeOptions 约束 |
| rowActions.maxInline | 2 | 整数 0–4；0 表示全部放入更多 |
| rowActions.display | text | text/icon-text/icon |
| rowActions.align | left | left/center/right |
| rowActions.gap | 12 | 整数 0–32 px |
| rowActions.grouped | true | boolean |
| toolbar.gap | 4 | 整数 0–24 px |
| toolbar.followView | false | 是否跟随命名视图 |

`rowActions.items` 按 Action.id 保存单项 label/order/position/display/group/separator；位置是 inline/more/hidden，display 还可 inherit。`toolbar.page/table` 按 ToolDefinition.id 保存 label/order/position/display/fixed/separator；位置是 direct/more/hidden。两种 position 枚举不同，不能混写。

工具 `fixed` 指窄屏保持直接显示，和列的左右冻结无关。`immutable` 工具保持直接展示。危险动作的名称和危险分组由代码保证，不能通过偏好改成普通按钮。

## 公共事件与命令

直接入口事件：`queryChange(Query)`、`configChange(TableConfig)`、`viewChange(id|null)`、`diagnostic(ConfigDiagnostic)`、`selectionChange(rows)`、`cellAction({action:'open'|'copy',row,column})`。配置入口显式事件：`preferenceChange(PreferenceV3)`、queryChange、viewChange、diagnostic。

直接入口引用可用：reload、setQuery、clearQuery、applyView、viewSnapshot、getState、getSelectedRows、clearSelection、selectQuery、readRows、openFilters、setFilterState、openColumnSettings、activateFeature、getFeatureContext、openDataTool 等。异步命令应 await 并处理失败；通过 Context 修改也受能力检查。

配置入口当前只显式公开 **reload、activateFeature、getFeatureContext、openDataTool**。需要直接 Runtime 命令时选用 BusinessTable，不能在配置入口引用上调用未公开方法。Custom/Headless 的上下文获取方式见[配置规范](03-配置与能力规范.md)。
