# 场景配置配方

以下 TS 片段展示局部配置，合并到自己的 columns/definition/props 中使用；完整组件和处理函数在[示例目录](../03-业务模块/01-接入示例/README.md)。字段名称和范围见[配置手册](08-配置字段手册.md)。

## 全部开放、仅开放基本、显示只读

全部开放见 [ConfiguredTable.vue](../03-业务模块/01-接入示例/ConfiguredTable.vue)。生产项目可缩小为：

```ts
import type { ColumnConfig, SettingsDefinition } from '@company/business-table'

const settings: SettingsDefinition = {
  pages: { columns: true, appearance: { enabled: true, disabled: true } },
  columnSections: { basic: true },
}
const columns: ColumnConfig[] = [{
  id: 'name', field: 'name', title: '名称', width: 220,
  configurable: { rename: true, width: { enabled: true, min: 120, max: 480 } },
}]
```

结果：可改名称和宽度；外观页可看但只读；未声明的排序、操作、工具栏与映射等设置隐藏。仍需开启 `features.columnSettings`。不要为了隐藏而用 disabled。

## 固定编号列，其他列可调整

```ts
import type { ColumnDefinition } from '@company/business-table'

const codeColumn: ColumnDefinition = {
  id: 'asset-code', field: 'code', title: '编号', visible: true, fixed: 'left', width: 160,
  configurable: { width: { enabled: true, min: 120, max: 240 } },
}
```

只开放宽度，显隐、冻结、顺序和改名入口不会出现。远端或 View 不能借偏好把锁定默认值改掉。若只是允许左冻结或不冻结，增加 `fixed: { enabled: true, allowedValues: [false, 'left'] }`。

## 数字原值与显示标签

```ts
import type { ColumnConfig, SearchDefinition } from '@company/business-table'

const status: ColumnConfig = {
  id: 'status', field: 'status', title: '状态', type: 'enum',
  mapping: {
    enabled: true, type: 'number', presentation: 'tag', empty: '未填写', unknown: '未知状态',
    items: [{ value: 1, label: 'A', color: '#067647', background: '#ecfdf3' }],
  },
  filter: { enabled: true, type: 'multi', source: 'mapping', search: true, counts: false, operators: ['in', 'notIn'], options: [] },
}
const search: SearchDefinition = {
  resetBehavior: 'empty',
  items: [{ id: 'status', label: '状态', kind: 'select', field: 'status', operator: 'eq', options: [{ value: 1, label: 'A' }] }],
}
```

界面显示 A，Search/列筛选/组合筛选最终查询使用数字 1。View 和方案保留数字类型，不保存 A 代替 1；远端恢复标签用 options.values，见[后台协议](09-查询与后台对接.md#原值显示标签与单位)。列映射不会自动声明 Search 选项，两者用途独立。

## 金额、万元和百分比

```ts
import type { ColumnConfig } from '@company/business-table'

const numericColumns: ColumnConfig[] = [
  {
    id: 'amount', field: 'amount', title: '金额（万元）', type: 'currency', align: 'right',
    numberRule: { enabled: true, style: 'decimal', scale: 10000, useGrouping: true, minimumFractionDigits: 2, maximumFractionDigits: 2, suffix: ' 万元' },
    filter: { enabled: true, type: 'number', source: 'data', inputUnit: '元', search: false, counts: false, operators: ['gte', 'lte', 'between'], options: [] },
  },
  {
    id: 'ratio', field: 'ratio', title: '完成率', type: 'percent',
    numberRule: { enabled: true, style: 'percent', percentBase: 'ratio', minimumFractionDigits: 2, maximumFractionDigits: 2 },
  },
]
```

原值 128000 显示 12.80 万元；0.1234 显示 12.34%。若接口给的是 12.34，则 percentBase 应为 percent。显示、复制、查询和导出用途不同：后台金额原值保持 128000，不按显示文本再解析成金额。

## 紧凑布局与按钮

```ts
import type { PresentationDelta } from '@company/business-table'

const presentation: PresentationDelta = {
  appearance: { density: 'compact', fontSize: 13, headerFontSize: 13, stripe: true, border: 'horizontal' },
  rowActions: { maxInline: 1, display: 'icon-text', gap: 8, items: { view: { position: 'inline' }, edit: { position: 'more' } } },
  toolbar: { followView: false, gap: 4, table: { refresh: { position: 'direct', display: 'icon', fixed: true } } },
}
```

这只配置外观，view/edit/refresh 必须在代码中有实际声明。不会凭空创建按钮。以固定高度容器包裹直接入口并设置 fill，可让表头固定、表体滚动；父容器本身必须有明确高度。

## 行操作与代码权限

```ts
import { createRegistry } from '@company/business-table'
type Asset = { id: string; locked: boolean }

export function assetRegistry(openEditor: (row: Asset) => void) {
  const registry = createRegistry<Asset>()
  registry.register('rowAction', 'edit', {
    id: 'edit', label: '修改', icon: 'edit',
    disabled: row => row.locked, handler: openEditor,
  })
  return registry
}
```

配置入口声明 `rowActions: { enabled: true, details: { allowedItems: ['edit'] } }` 并传 registry。函数参数 openEditor 是接入方真实业务动作。直接入口则把 Action 数组传给 actions；支持 children 子菜单、visible/disabled 行谓词。服务端仍须验证提交权限。

工具使用 `ToolDefinition[]`，处理函数接收 Event，不能直接复用接收业务行的 Action handler。子菜单需要真实可用子项；没有 handler 的普通工具不渲染为假按钮。两种组件的内置工具区渲染 tools.table；tools.page 提供页面工具声明及可配置布局，页面渲染由宿主负责。当前 `ToolStrip` 是仓库内部组件，**不是公开包导出**，包消费方不要从私有路径导入。报价 Demo 是仓库内共享组件使用参考，外部接入可先使用 tools.table，或通过自己的页面工具 UI 消费布局并保持权限检查。

## 自定义单元格

简单插槽使用 `#cell="{ row, column, value, text }"`，text 是共享解释器生成的显示文本。复杂渲染用 Registry 的 renderer 字符串 ID，handler 代码留在业务系统：

```ts
import { h } from 'vue'
import { createRegistry } from '@company/business-table'

const registry = createRegistry<{ id: string; name: string }>()
registry.register('renderer', 'asset-name', value => h('strong', String(value ?? '')))
```

列声明 `renderer: 'asset-name'`，配置入口传 registry。模板或远端 JSON 不能包含 JS/任意 Vue template；未知 renderer 回退文本并诊断。自定义 renderer 的展示不自动变成导出字段语义，导出使用列解释器。

## 内容显示与富文本模板

普通说明、复制和换行先用 content；需要组合多个列的显示文本时再用 template。下面是完整的局部列数组：

```ts
import type { ColumnConfig } from '@company/business-table'

const columns: ColumnConfig[] = [
  { id: 'asset-code', field: 'code', title: '编号' },
  { id: 'asset-name', field: 'name', title: '名称', content: { wrap: 'two', copyable: true, emptyText: '未填写' } },
  {
    id: 'label', field: 'name', title: '物料说明',
    template: { enabled: true, document: { ops: [
      { insert: { field: 'asset-name' }, attributes: { bold: true } },
      { insert: ' / ' },
      { insert: { field: 'asset-code' } },
      { insert: '\n' },
    ] } },
  },
]
```

模板 token 的 field 使用**列 ID**（asset-name），普通列的 field 才是行数据字段（name）。先从目标列取得共享显示文本，再合成模板；不是递归执行另一个模板，也不是计算字段。缺失 token 会被校验处理，不执行任意脚本。可在列设置“试算”中输入临时值检查显示与导出，但试算不保存业务行。

## 条件标记和报告

完整的四项开关与字段定义见[数据工具规范](07-数据工具接入与行为.md)及 ConfiguredTable 示例。条件标记局部配置如下：

```ts
import type { ConditionalFormattingDefinition } from '@company/business-table'

const conditionalFormatting: ConditionalFormattingDefinition = {
  allowedColumns: ['amount'], defaultColumn: 'amount',
  defaultRules: [{ id: 'large-amount', enabled: true, condition: { field: 'amount', operator: 'gte', value: 10000 }, label: '较大金额', color: '#b54708', background: '#fffaeb' }],
}
```

规则按原始金额匹配，默认只应用首条命中规则；若用户保存过空规则数组，则表示已经清空，不重新套用 defaultRules。groupColumns/summaryColumns 等使用列 ID；condition.field 使用业务字段。

## 导出与模板

[ExportTable.vue](../03-业务模块/01-接入示例/ExportTable.vue) 是可复制起点。ExportDialog 接收 fields 与 groups；groups 中的 rows 必须已经是对应范围的快照，不会靠一个“全部结果”标签自动查询后台。

需要继承用户列设置时：先读取 `table.getState().columns`，按固定业务字段 ID 匹配最终 ColumnConfig；保持标准 label，用户标题在 column.title。valueMode=raw 保留原值，display 使用显示解释，both 对有映射/规则的字段可拆分原值和显示值。导出方案通过 presets/savePresets 单独保存。

模板使用固定 TemplateDefinition，不从当前可见列生成；field.hint 描述填写规则，choices 可以提供固定选项，examples 进入独立示例工作表。下载模板不代表实现了导入校验和入库。
