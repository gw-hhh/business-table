## 验证结果

- 文档审计：93 篇 Markdown，目录、链接、锚点及索引通过；交付文档补全后再次审计。
- portability、61 个 SFC 语法、vue-tsc、ESM/UMD/声明和 Demo 构建通过。
- Vitest：85 个文件、664 项测试通过。
- 发布包：335 个文件、独立消费及 11 个 TypeScript/Vue 文档示例检查通过；Bundle 静态依赖检查通过。
- Playwright：开发与生产预览合计 199 项通过，4.8 分钟；运行错误采集通过。
- 日志：[release-gate.txt](release-gate.txt)。没有使用测试数量推断全面旧版视觉一致。

## 初次失败与修正

定向浏览器检查先发现查询圆点辅助文字改变按钮名称，已给查询按钮明确可访问名称。独立代码审查发现外部筛选状态读取了普通 filters，已改为 columnFilters/filterGroup，并补列头筛选用例。

第一轮完整浏览器检查 193 通过、6 失败：旧测试在没有设置弹窗的场景误调用展开助手，以及新对齐测试在抽屉动画期间先后采集位置。已删除错误助手调用、等待可稳定满足的几何对齐，保持原断言精度；第二次完整门禁全部通过。失败日志曾包含本机绝对路径，被 portability 拦截，清理路径后重新执行完整门禁。

## 边界

这是本地组件与 Demo 验收，不代表真实后台权限、readAll 性能或服务端聚合已验收。启用远程汇总依赖完整读取能力，沿用最多 10000 条上限，查询/刷新可能增加完整读取次数；错误不会退化成当前页汇总。此版本支持单数值列求和，显示遵循该列的数字格式。此前反馈的 grow 列手动宽度优先级不属本批。推送不等于 main 合并、正式发布或远端 CI 已通过。
