# 跨平台滚动验收修正

日期：2026-09-23。分支：development。

## 远端失败证据

提交 `b476446` 的 [verify](https://github.com/gw-hhh/business-table/actions/runs/35852612077) 与 [delivery](https://github.com/gw-hhh/business-table/actions/runs/35852612013) 未通过：433 项单元测试通过，浏览器 111 项通过、2 项失败。两项均为同一滚动布局用例在开发与预览项目中的跨页面严格等高断言，预期 352px、实际 353px。

delivery 失败产物中的 trace 显示 Vue 表体最终高度 353px，横向滚动条为 `height: 0px; visibility: hidden`。旧版页脚说明采用 normal 行高，Vue 为 16px，两者均参与整页 flex 高度分配；跨系统字体可能改变页面剩余高度，不能把跨页严格相等作为无多余滚动条行的唯一证据。

## 修正与边界

- 跨页面表体高度差限定为 1 CSS 像素，与现有固定列、表头和表宽比较保持一致。
- 新增本页高度预算：容器可用高度减表头和表体高度的绝对差不超过 1 像素。
- 横向滚动条高度必须严格为 0，滚轮操作后纵向位置必须增加，继续验证真实行为。
- 无业务源码、旧版参照、依赖或平台分支逻辑改动。

## 本地复验发现的就绪时序

首次完整复验为 112 项浏览器通过、1 项固定列滚动失败（横向位置预期至少 100px，实际 2px），日志 `.vite/layout-platform-release.log`。trace 证明滚轮发出时操作列尚未挂载，表体宽 1022px、可用宽 1020px、横向轨道隐藏；约 0.54 秒后操作列出现，表体变为 1218px、轨道为 15px，但先前滚轮已被旧范围截断。测试增加操作前的实际横向范围检查（至少 150px），保留滚动后至少 100px 及固定列位置要求，不使用固定延时或自动重试掩盖失败。
