### 审查与回归修复

- 配置解释复用真实解析流程，记录合法归一化值、拒绝原因和派生来源；普通解析不生成解释记录。
- Runtime 缓存对普通、浅响应式和含原始子节点的输入保留即时检查，避免原地修改定义或映射顺序后结果过期。
- 空状态收到独立查询快照；修改插槽参数后重试不会改变 Runtime 已应用条件。
- 虚拟行的异步焦点恢复使用会话和焦点归属检查，过期请求不会夺回用户已经移走的焦点。
- 设置快速关闭重开使用新的 UI 会话，已取消的草稿不复活；离场动画与嵌套滚动锁、焦点返回共用生命周期。
- 首次完整门禁发现工具栏测试使用脱离文档的锚点，与真实浮层生命周期不符；修正为挂载到 document.body，保留锚点脱离时关闭浮层的生产行为。首次记录见 [release-gate-first-attempt.txt](release-gate-first-attempt.txt)。
- 第二轮门禁的 173 项浏览器用例通过，但日志发现非 deferClose 的区域选择 Feature 被传入 afterLeave 事件。修正共享 FeatureHost 为显式加入协议时才传递 open/afterLeave，新增 fragment Feature 回归先复现警告，再修复通过；三个相关测试文件共 17 项通过。保留[修复前门禁记录](release-gate-before-feature-host-fix.txt)，最终完整门禁重新验证冻结后的代码。
- 后续浏览器复验发现两处测试不稳定：1000 行完整渲染的首次就绪超过默认 5 秒，以及进入动画期间 920px 边界实测为 919.9999389648438px。trace 显示约 25 秒后页面已有完整 1000 行、aria-busy=false、运行错误为空，HTTP 均为 200。性能用例的就绪等待单独设为 60 秒，保留 90 秒总限及所有结构/交互断言；宽度断言精确到小数点后两位。其余 171 项通过，详见[修复前浏览器记录](release-gate-before-browser-wait-fix.txt)。

## 边界

- Chromium 开发及构建预览用于本地回归，不代替业务后台、屏幕阅读器和全浏览器验收。
- 配置解释是 supplied snapshot，仅覆盖 columns/pagination/presentation，不追踪 live Runtime/Feature/settings。
- 虚拟滚动仍需浏览器持有查询结果，不能代替服务端分页和大数据导出。
- 当前性能示例为七列、520px 高度；耗时包括导航、资源加载和等待首行可见，受机器负载影响，不是纯渲染耗时或跨设备性能承诺。
- 受控 open 的共享弹层支持退出动画；业务记录、导出和模板的最外层组件若由父级 v-if 整体卸载，仍立即清理，不等待其内部动画。
- Demo 构建仍有依赖大块超过 500kB 的提示；实际库入口预算检查通过，未提高预算或隐藏警告。Node 的 NO_COLOR/FORCE_COLOR 提示不影响执行结果。
- 用户没有要求设置历史，本批不实现；未宣称 Legacy 全量视觉验收完成。
