# 设置表单按内容排版验收

## 范围

2026-09-29，development，基线 bdc4d60。根据用户反馈，把设置中的等宽分栏改为按内容长度分配宽度。覆盖列编辑、表格外观、操作默认布局、工具通用设置和排序规则；不改变业务值、草稿、权限和持久化。

## 修改文件与设计

- `src/features/settings/settings-pages.css`：共享 `bt-settings-form`，普通字段 180px、短选项 128px、滑条基础 230px（可扩至 300px）、颜色组合 260px，长文本可伸展；全部受父容器宽度约束并自然换行。
- `src/components/ColumnSettingsDrawer.vue`、`src/features/settings/{ActionSettings.vue,AppearanceSettings.vue,ColumnRuleEditor.vue}`：按字段用途应用上述布局。日期和布尔类型等较长选项保留普通宽度；币种、显示单位不再强制整行。
- `src/components/column-settings.css`：排序行限制总体宽度，升降序占 112px；窄屏继续两行排列。
- 工具/操作列表短下拉设置轨道上限，名称列吸收剩余空间；工具通用设置自然换行。
- `tests/e2e/settings-refinement.spec.ts`：现有响应式回归保留断言，扩充四个设置页的窄屏截图。
- 文档同步当前状态、界面规范、README、CHANGELOG、版本和验收索引。
