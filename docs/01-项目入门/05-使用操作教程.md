# 使用操作教程

适合先体验功能、再决定开放哪些配置的使用者。以下路径以开发服务显示的地址为准；例如服务在 5173，访问 `http://127.0.0.1:5173/?example=config`。先阅读[本地运行](02-本地运行与接入.md)，开发接入见[逐步教程](06-逐步接入教程.md)。

## 先选择体验页面

| 路径 | 用途 | 应看到什么 |
| --- | --- | --- |
| `/` | 报价完整 Demo | 报价业务字段、查询、视图和业务动作 |
| `/?example=config` | 全部已实现配置 | 列、排序、操作、外观、工具栏与数据工具 |
| `/?example=config&mode=readonly` | 只读 | 部分设置可见但不可修改，其他设置仍可编辑 |
| `/?example=config&mode=unconfigured` | 未配置 | 未声明的设置和数据工具入口隐藏 |
| `/?example=config&mode=core` | 最小表格 | 仅数据、列和基础分页 |
| `/?example=config&mode=custom` | 自定义设置界面 | 业务自定义 UI 调用同一列宽修改命令 |
| `/?example=config&mode=headless` | 无默认设置 UI | 通过示例按钮读取并修改允许的设置 |
| `/?example=config&mode=off` | 后台关闭 | 本地已声明的部分功能被远端开关关闭 |

配置演示页底部输出偏好差量用于观察接口，**它没有接入 `savePreference`，不要用它验证刷新后的设置保存**。报价 Demo 有本地持久化；需要完整的配置入口保存示例，使用 [ConfiguredTable.vue](../03-业务模块/01-接入示例/ConfiguredTable.vue)。

## 查询与筛选

1. 在查询区填写条件。编辑的是草稿，点击“查询”后才影响表格和正式摘要。
2. 表头列筛选用于单个字段；组合筛选用于多个规则和 AND/OR 组合。基础查询、列筛选、组合筛选可以同时生效。
3. 摘要显示可读标签，实际查询仍使用原值。例如“已确认”可以对应数字 `1`。
4. 删除一条标签只移除该条件；清除全部条件保留布局和排序。重置是否恢复默认条件由 `resetBehavior` 决定。
5. 组合筛选中可保存筛选方案。载入方案只更新草稿，需要“应用条件”才查询；不要把载入与应用混为一步。

筛选方案保存的是列与组合条件；命名视图还可带搜索、排序、每页条数和布局，二者用途不同。完整保存范围见[持久化指南](../02-架构与规范/10-偏好与视图持久化.md)。

## 调整列与表格设置

1. 快捷列面板用于显隐、顺序和冻结；“更多设置”进入完整抽屉。
2. 左侧选择列，右侧查看“基本 / 内容 / 数字 / 筛选 / 映射 / 模板 / 试算”等已开放模块。数字模块只在数字、金额、百分比列显示。
3. 当前编辑标题与模块导航固定，表单区独立滚动。点击分组标题可展开、收起，不会丢失当前草稿。
4. 拖动可排序项时，插入线表示放下后的落点；冻结使用左、右按钮，再点已冻结侧可取消。
5. 字号、列宽、间距、小数位等范围数值可以拖滑条，也可精确输入。每页条数、密度等固定选项继续使用选择控件。
6. 点击“应用”才提交本次设置；取消保留正式状态。恢复此列、恢复模块与全部恢复作用范围不同，操作前查看当前所在分组。

无效数字草稿会阻止应用：例如清空必填数字、超过范围、最大小数位小于最小值。即使切到别的页签，错误仍需修正；恢复对应分组可回到合法默认值。列级文字样式可继承全表；没有必要给每列重复指定相同字体。

“试算”仅用临时输入检查显示与导出解释，不修改数据，也不是公式引擎。富文本模板是受约束的文档数据，不支持任意 HTML 或脚本。

## 操作按钮、外观和工具栏

| 页面 | 可调整内容 | 注意点 |
| --- | --- | --- |
| 排序规则 | 多字段优先级、升降序、顺序 | 查询行为变化会回到第一页 |
| 操作按钮 | 行内数量、图标/文字、间距、更多菜单、分组 | 业务处理函数与权限来自代码，改布局不会获得新权限 |
| 表格外观 | 字体、字号、密度、边框、斑马纹、序号、悬停和每页条数 | 表头与正文可分别设置；每页条数须属于允许列表 |
| 工具栏 | 页面/表格工具的名称、位置、显示形式与顺序 | 空区域隐藏；个人隐藏的工具可在设置里重新开启 |

工具栏“随视图”决定布局是否跟随命名视图；默认不跟随。窄屏会把未固定的直接工具放到“更多”，不会改写保存的位置配置。页面工具栏需由宿主接入相同 tools 与布局，见[场景配方](../02-架构与规范/11-场景配置配方.md)。

## 视图、导出和数据工具

- **视图**：应用查询后另存当前状态；后续修改布局不会自动覆盖同名视图。系统视图用于清查询并保留个人布局；只读视图不可修改。
- **导出**：选择范围、字段、顺序、原值/显示值，确认预览后下载 Excel 或 CSV。远程完整结果依赖 `readAll`，不能用当前页冒充全部结果。
- **模板**：固定业务字段、说明与示例独立于个人列显隐。当前提供模板下载，不代表已有 Excel 导入。
- **条件标记**：按原值判断，命中首条启用规则后标记行，不改变查询结果。
- **分组汇总**：对完整查询按一至两级字段分组，可展开、收起和导出。
- **记录对比**：从查询结果选 2–4 条、指定基准、只看不同项及导出。
- **区域选择**：仅当前页可见数据列，支持拖动、方向键、Shift 扩选、复制及统计；不等于业务行勾选，不保存到视图。

设置历史按项目要求不提供。服务端大数据导出、公式引擎和服务端权限/版本冲突仍需后续接入，见[当前状态](03-当前状态.md)。

## 一次完整试用

在报价 Demo：查询一个状态 → 增加金额组合条件 → 查看摘要与结果 → 修改列宽/字号 → 应用 → 另存视图 → 切回系统视图 → 再载入命名视图 → 导出当前查询。刷新浏览器后检查本地视图；跨账号、跨浏览器共享需接入后台存储。

遇到入口不显示、设置保存失败或摘要只有数字，按[常见问题](07-常见问题与排查.md)逐项检查。
