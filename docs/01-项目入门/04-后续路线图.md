## 执行原则

不要以补丁方式开发。

如果当前设计无法支持需求：

优先重构底层架构。

禁止：

- App.vue 堆逻辑
- 页面特殊判断
- 临时状态
- 重复 Feature

## 后续任务

### BT-01 Query Runtime

已实现并纳入 `development`：迁移搜索、高级查询、查询状态和 View 中的 Search 值保存。提交与 Release Gate 结果以当前分支和验收记录为准。

### 设置策略与工具接入增量

当前代码已统一设置显示与只读：直接入口 settingsDefinition，配置入口 definition.settings；pages、columnSections、column.configurable 三层交集。缺失、false、enabled:false 或 visible:false 均隐藏，true 可编辑，显式 disabled 才只读。远端只能收窄；设置写入守卫覆盖默认 UI、Custom、Headless、恢复备份和重置，读取时保留已有合法只读值。

工具设置与真实按钮共用 tools/presentation，空区域隐藏。报价 Demo 与默认配置示例开放全部已实现设置，并提供只读／未配置示例。宿主重新创建内容相同的分页配置对象或选项数组不再重置当前设置。继续开发时复用这些通用策略，不在页面增加模块权限分支。完整发布门禁结果以本批实际验收记录为准。

### BT-02 View Runtime

本地部分已实现：Views Runtime/ViewsPanel 共用创建、更新、重命名、默认、重排、删除与持久化，管理状态已迁出 Demo。后续补服务端权限与版本冲突协议，需由业务后台适配器提供真实接口。

### BT-03 Mapping

完善字段值映射规则与独立 Runtime；当前已有列级映射和显示基础能力。

### BT-04 Formatting

完善日期、金额、百分比等格式化能力；保留现有列格式和显示／导出一致解释。

### BT-05 Template

实现模板生命周期。

### BT-06 Export

本地部分已实现：Excel/CSV、范围、字段选择/顺序、显示与原值、导出方案、预览和模板下载。后续接入服务端大数据导出。

### BT-07 Data Tools

用户已选择先完成组合筛选及方案、摘要和视图联动。本批开放数据工具中的组合筛选与工具栏设置，保留嵌套条件组；统一方案 Runtime 和原子查询重置，见[本批验收](../06-验收记录/2026-09/2026-09-23-组合筛选与查询摘要对齐/README.md)。条件标记、分组汇总、记录对比、区域选择、设置历史仍待后续安排。

### BT-08 Formula Engine

实现计算字段、公式引擎及相关试算。当前设置页的“试算”仅核对列显示与导出结果，不能替代本任务。

### BT-09 Legacy Full Acceptance

持续以旧版实际页面对照。不得用单测通过替代视觉确认；本轮验收范围、证据和剩余边界见 docs/06-验收记录/2026-09/2026-09-23-旧版交互与视觉对齐/README.md。

## 当前接续规则

除暂缓的数据工具外，继续以旧版页面、样式、布局、功能和动画为对照。开发先检查旧版实际行为，复用已有组件和 Runtime；不得恢复 Demo 私有视图 CRUD、CSV 拼接或独立设置状态。配置或功能改变时同步 README、配置规范、接入说明与当前状态；文档和分支整理见[本轮版本记录](../04-版本记录/2026-09/2026-09-23-04-开发分支与文档体系整理.md)。

## 开发分支

日常修改和提交优先在 development，main 保留正式基线。默认不新建功能分支；完成本地验证后按用户授权推送 development。历史计划中的“从 main 新建 feature”不再作为当前工作流。
