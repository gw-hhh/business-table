## 对齐原则

旧版决定布局、尺寸、文案、图标、状态和交互；新实现仍然是 Vue 3 + TypeScript + VXE 的通用业务表格。禁止正式 src import reference、复制旧运行时、使用 iframe 代替迁移，或用不能工作的按钮冒充已实现能力。业务查询字段、报价数据、业务表单留在 demo/宿主；分页、密度、列设置和菜单由组件内置。保留原有 Provider 取消/序列保护和分页回归。
