# Legacy 交互与视觉对齐

> 历史记录：保留本批发生时的结果、分支和限制，不作为当前开发规则。2026-09-23 归档时仅调整文档路径；当前状态与分支流程请从[文档导航](../../README.md)阅读。

## 范围

以 `reference/legacy-v3.1/quotation-manager-v3.1/index.html` 的实际操作为依据。用户明确暂缓“数据工具”菜单及其中未实现高级能力；查询、列筛选、视图、设置、导出、记录操作仍在本次范围。保留未配置隐藏、显式 disabled 才只读的通用策略。

## 已发现的差异

- 首屏默认视图、排序、高级查询展开、批量选择、行高、分页与旧版不同。
- 列头缺菜单和可访问的列宽调整；排序入口未复用设置排序页。
- 视图 CRUD 在 Demo，通用 Runtime 未接入实际页面。
- 导出直接下载 CSV，未呈现旧版范围、字段、方案、预览和 Excel。
- 新建/编辑/查看用居中表单，旧版为右侧抽屉。
- 设置预览、工具行复选框布局、列分区切换等与旧版不一致。
- FilterOption 已分 value/label，但远端恢复摘要缺少按已选值查询标签的链路。

## 实施顺序与归属

1. Main/Grid：对齐默认状态，通用列头组件、菜单和列宽；复用 Settings 排序入口；对齐查询与摘要布局。
2. Settings/Columns/Presentation：逐页对照控件、预览、键盘、拖动、数字规则，保持策略守卫。
3. Views/Export：通用 Runtime 与 UI，Demo 仅传数据、字段和 handler。
4. Filters/Search：摘要使用 displayValue，保存和查询只使用保留类型的 value；支持远端选项恢复。
5. 对照旧版操作，更新迁移矩阵、配置说明、交接与验收记录；执行完整 Release Gate 后本地提交，等待用户体验验收再推送。

## 验证

每个行为差距先补可复现的测试；浏览器比较首屏、展开查询、菜单、设置各页、视图、导出、详情/编辑与窄屏。旧版 reference 仅作为静态与行为参考，不参与正式构建、不运行于 Vue 页面。测试通过与视觉验收分别记录；未覆盖或未对齐项不标为完成。
