# 剩余数据工具对齐计划

日期：2026-09-23；分支：development；基线：12a872f。用户要求继续完成剩余能力，并明确排除设置历史。

## 目标与设计

以 quotation-manager-v3.1 的实际页面为基线，完成条件标记、分组汇总、记录对比、区域选择。旧版文件保持原样；功能默认关闭，报价 Demo 和完整配置示例显式开启。设置历史不迁移、不增加入口。

采用独立 Feature 与共享 Runtime。条件标记写入现有配置事务和 View；分组与对比通过完整查询读取接口取得只读数据；区域选择仅保存当前页临时选区。所有 UI 共用平台类型、字段解释、弹层和错误处理，不把这些状态放入 Demo。

## 模块与契约

- `features/conditional-formatting`：`ConditionalRule` 包含稳定 id、类型化 condition、enabled、24 字以内 label、前景色和背景色。规则最多 30 条，首个启用命中者生效；条件使用原值，与列筛选开关、显示缩放独立。抽屉保存草稿，失败保持输入。
- `runtime/useTableRuntime.ts`、配置与视图协议：新增可选 conditionalFormatting，旧数据无该字段时兼容。Gate 开启后恢复规则投影，UI 仍交互时加载；`setConditionalRules` 在既有写队列中单次持久化，成功后发布。View 保存与恢复规则，系统视图保留布局，字段和只读约束不可绕过。
- `features/reports`：分组至多两级，字段、默认分组、明细列、汇总列由声明提供。对比选择 2–4 条，检索、基准、仅差异与导出均不修改原表。Context 读取完整查询、取消旧请求、拒绝迟到结果；没有 readAll 时明确报错，不能用当前页冒充全量。
- `features/range-selection`：独立启停、矩形选择、方向键与 Shift 扩选、Escape 清空、复制 TSV、精确数值统计。查询、页码、数据或列布局变化清空选区；业务行选择独立。剪贴板不可用时提供手动复制内容。
- `BusinessTable` / `ConfiguredBusinessTable`：接入四个 Feature、类型化配置、默认／自定义／Headless Context，表格单元格只消费投影。业务 Demo 只声明字段和工具动作。
- 精确统计复用 decimal/BigInt，显示通过 evaluateCell，XLSX 仅点击导出时加载。大于 Excel 精确位数的金额保存为文本，不通过浮点数截断。

## 审查重点与验收边界

保存期间切换表格或撤销权限、异步全量结果晚到、相同显示文字但不同类型原值、隐藏或移除的字段、负数与超大精确金额、固定列与窄屏选区、查询变化后的对比临时选择。严格保留查询/业务数据；只读统计不改分页和排序。

仓库当前没有业务后台工程，实际 DataSource 使用本地示例。真实后台需用户提供接口资料；模拟适配器与接口契约检查不等于后台验收。本轮不自动推送远端。
