# 设置布局与首次打开优化

## 目标及边界

优化设置与模板冷启动、统一紧凑层次、移除重复提示及设置备份。保持通用 Feature/Runtime/Config/Persistence 边界，不修改只读旧版文件、主分支、业务备份或持久化格式。

## 实施顺序

1. 检查首次模块下载及挂载路径，补充意图预加载的去重、无副作用、权限与失败测试。
2. 共享模块加载器、Feature/工具接口、模板加载反馈，设置目标在挂载前准备。
3. 重排共享分组标题、数值控件、操作列表、条件标记，更新视图指示。
4. 桌面/窄屏浏览器检查、完整门禁、文档审计及提交推送。
