# 渲染性能与交互诊断优化

## 范围与边界

本轮按已确认的建议实施性能、共享交互、动效和配置来源诊断。继续在 development 开发；不添加设置历史，不更改双击列宽恢复默认的行为，不修改旧版参考文件。

| 模块 | 设计与归属 | 验证 |
| --- | --- | --- |
| 渲染 | TableSurface 使用 VXE 原生纵向虚拟滚动；公开 height/maxHeight/virtualRows；不改变默认换行和自动行高 | 大页/无分页浏览器 DOM 数量、尾行可达、固定列与多行 |
| Runtime | 响应式缓存定义/列签名；关闭自动查询时不订阅或克隆查询草稿 | 深层变更、类型、定时器、缓存失效回归 |
| 空状态 | 共享 empty slot 传递结果原因、query、reload/clearQuery；默认不主动清空业务条件 | 空数据/条件无结果/错误/加载及自定义内容 |
| 浮层和动效 | 共享滚动策略 close/follow，保留默认策略；生命周期负责焦点和锁；减少动态效果系统设置优先 | 内部滚动、嵌套、卸载、退出及键盘排序 |
| 列宽 | 原有拖动引导线增加即时像素数值 | 边界、取消、提交、只读 |
| 配置诊断 | 显式 explainConfiguration 检查给定快照，记录 resolver 各层合法值和拒绝原因 | 权限、身份、来源；普通解析不分配 trace |

## 实施步骤

1. 明确公共类型及文件职责，并行实现 Runtime、共享交互和配置解析。
2. 实现渲染、空状态、列宽反馈及可运行性能示例。
3. 执行针对性测试与浏览器性能比较；独立审查实际差异。
4. 更新用法、字段说明、当前状态、版本及验收索引。
5. 执行完整 verify:release；记录真实结果后提交、推送 development。

## 验收原则

性能时间为本机单次样本，不作为跨机器 SLA；结构性断言验证虚拟窗口有界与滚动后内容正确。后台协议、屏幕阅读器及全浏览器覆盖不能用本地 Chromium 测试代替。

## 执行结果

实现、审查、文档及完整门禁已完成：647 项单测、173 项浏览器用例、10 个公开包文档示例编译通过。实际测量、回归修复、文件清单与剩余边界见[本批验收](../../06-验收记录/2026-09/2026-09-29-渲染性能与交互诊断优化/README.md)。
