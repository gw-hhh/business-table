# 组合筛选对齐计划

日期：2026-09-23。分支：development。用户已确认本批范围为组合筛选及方案、摘要和视图联动；条件标记、分组汇总、记录对比、区域选择与设置历史仍待后续批次。

## 目标与设计

以旧版实际数据工具菜单、580px 筛选抽屉、条件编辑和同一行摘要为参照。复用现有 Filter AST、Query Runtime、Feature Gate 和 View 协议；数据值与显示标签保持分离，不执行旧版代码。保留新版已有嵌套组与独立方案能力，方案管理通过独立入口打开。

旧版没有独立筛选方案；方案属于平台增强，必须沿用原值协议、取消不应用和失败不发布。默认 UI、Custom、Headless 共用 Filters Context 的方案 Runtime；Feature 生命周期负责释放。组合筛选清空只影响组条件；摘要“清除条件”一次重置基础、列和组条件，保留布局、排序和视图标识，基础查询遵循其 resetBehavior。

## 边界与接口

- `src/features/filters/context.ts`：增加共享 `plans` 与 `readPlan(id): FilterState`，返回经当前字段能力检查的副本；撤销后旧命令不得再写入。
- `src/runtime/query.ts`、`useTableRuntime.ts`：提供 `clearQuery(): Promise<void>`，一次重置三个查询层并只请求一次；Search Context 增加 `remove(id)`，移除已应用标签不会提交其他未应用草稿。
- `src/components/QuerySummary.vue`：组合基础与表格条件呈现，消费 Runtime 命令，不另存一份查询。`querySummary` 是可选的统一摘要入口；旧 SearchSummary 入口继续兼容。
- `src/features/toolbar`：工具子菜单是通用声明，空菜单隐藏，显式 disabled 才禁用；支持键盘、关闭回焦和实时可用性检查。设置预览中的子项也不可执行业务动作。
- `src/features/filters/FilterFeature.vue`：只管理临时编辑草稿与对话框；方案状态改为 Context 提供；方案读写失败不修改查询、不丢失草稿。
- `demo/App.vue`：只声明数据工具及已实现的菜单项，调用平台打开方法，移除重复摘要接入。

## 审查重点
