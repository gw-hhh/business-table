# 报价演示模块

报价管理是 BusinessTable 的第一个接入与旧版对照场景，不是平台核心。旧版 [index.html](../../reference/legacy-v3.1/quotation-manager-v3.1/index.html) 定义产品行为；当前 [App.vue](../../demo/App.vue) 组织页面，[报价模型](../../demo/quotation/model.ts)、[本地仓库](../../demo/quotation/repository.ts)和[记录抽屉](../../demo/quotation/QuotationRecordDialog.vue)承接报价业务。通用接入分工见[多业务接入边界](02-多业务接入边界.md)。

## 业务数据与查询

示例初始有六条报价。记录包含编号、项目、客户、人民币元金额、状态、负责人、大区、创建日、有效期与备注；演示数据的金额字段是元数值，状态使用中文值，不能把旧版的整数分和状态编码直接当作新版通用协议。报价特有的字段、列、状态选项、日期和金额校验均留在 Demo。

查询栏提供关键词、客户、状态、大区、负责人和创建日期。关键词匹配报价编号、项目和客户；“未结”由搜索定义投影为草稿或评审中，不在 BusinessTable Core 写报价判断。Demo 的数据源把通用基础条件、列条件和组合条件作用于报价集合，再返回分页结果；视图保存 Search 值和查询展开快照，查询区控件另有独立持久化偏好。页面通过通用工具子菜单提供“数据工具 → 组合筛选／条件标记／分组汇总／记录对比／区域选择／工具栏设置”，调用平台打开命令。统一摘要由 BusinessTable 的 querySummary 提供；页面不保存额外筛选状态。

## 已接入的操作

- 新增、详情、修改、复制为草稿及删除由 Demo 的记录抽屉和业务仓库执行。删除与覆盖恢复先确认；保存失败保留编辑输入，刷新后才能读取其他页面写入的记录。
- 批量选择、页内选择和查询范围选择走表格选择 Runtime。页面根据完整查询结果计算筛选合计，根据当前选择计算所选合计；金额汇总规则属于报价业务。
- 命名视图使用通用 Views Runtime/ViewsPanel，报价页只提供初始视图和本地保存接口。工具条读取同一份工具声明与布局；导出对话框支持本地 CSV、Excel、范围、字段与方案，模板下载读取固定业务字段定义。
- JSON 备份是当前 Demo 自有的 `quotation-demo` v1 协议。恢复先解析、逐条校验、检查重复编号，再经确认整批替换；它不等于旧版报价备份或平台 Preference 的直接兼容转换。

## 本地持久化与范围

记录、视图、偏好和导出方案使用不同的浏览器存储键。记录仓库限制最多 10000 条，以本地版本和存储内容比对防止本页过期写入；写入失败不发布新行，跨标签变更只提示刷新。首次读取失败会进入临时模式并保留原存储内容。浏览器清理数据、更换浏览器或更换地址可能使本地记录不可见；当前没有业务服务器、真实登录权限或跨客户端事务保证。

组合筛选、独立筛选方案、查询摘要和视图联动已接入；本轮开发分支另接入四项数据工具，金额列用于条件标记、汇总和统计示例。通用配置与状态归属见[数据工具接入与行为](../02-架构与规范/07-数据工具接入与行为.md)。设置历史按用户本轮决定不迁移。服务端大数据导出、旧备份显式转换、服务端视图权限和版本冲突仍需单独接入与验收；当前状态见[项目状态](../01-项目入门/03-当前状态.md)。
