# 旧版视觉还原：本地验收批次

用户于 2026-09-21 明确要求按旧项目 index.html 和六张截图还原样式。当前配置验证页不再作为产品视觉交付；报价 Demo 采用旧版的页面布局与交互。继续修正尚未验收的本地 `feature/config-runtime`，不推送，不改变 main/development。

## 基准

- 1920 × 945 同一视口：页面边距 24 px；页头 60 px；主卡片从 y=96 开始；查询两行；工具栏 56 px；表头 44 px；内容区域撑满可用空间；分页固定在卡片底部。
- 以 reference 中 styles → custom → enhancements → refinement 的最终级联为来源，核对字体、行高、留白、颜色、边线、按钮、状态标签、hover/focus/disabled。旧版只作为参照，生产代码不引用它。
- 必须截图验证主页面、行 More、页头 More、我的视图、快速列设置、完整设置抽屉六种状态。
- 默认报价样例采用截图中的澄川水务筛选；全部报价仍可进入。配置验证页保留在 `?example=config`，避免删除已有验证能力。

## 实现边界

1. 通用组件保留 VXE 二次封装、数据查询和配置能力。增加布局插槽、可控查询、独立选择状态、表格留白及精细样式。行操作改为文字按钮和浮层菜单。
2. 列设置改为草稿 → 预览 → 确认，保留 capabilities 校验。快速面板和完整抽屉共享草稿；取消不修改正式配置。文字样式使用明确且可验证的可序列化字段。
3. 报价标题、搜索字段、业务动作、数据/备份与视图示例放在 Demo。主组件不承担报价业务。
4. 未迁移的设置能力不伪装成可用；矩阵逐项注明本批真实覆盖范围。

## 验证

行为变化先写失败测试，再实现。保留现有查询并发、懒加载、权限和配置回归。追加外部查询/选择、草稿确认取消、菜单定位及关闭、页面几何与窄屏验证。最后运行完整 Release Gate：类型、Vitest、库和 Demo build、Playwright；四路浏览器错误均为 0。人工逐张查看同尺寸截图，不能用测试绿灯代替视觉验收。
