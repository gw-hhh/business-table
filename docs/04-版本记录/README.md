## 新增记录

1. 使用[版本说明模板](00-版本说明模板.md)，文件名为 `年-月-日-当日顺序号-中文主题.md`，同一天按 `01` 起递增，已发布的编号不改。
2. 写清实际变更、兼容影响、验证证据、升级与回退、未完成项。正式发布才填写经确认的产品版本。
3. 更新月份索引、本页最近变更和[当前状态](../01-项目入门/03-当前状态.md)，涉及用法时同步对应说明。
4. 历史记录不改写成最新结果；勘误注明日期与原因。本月补录记录均链接原验收，原文未记录的信息不作推断。
