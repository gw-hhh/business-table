# 版本说明模板

复制到月份目录，改为 `年-月-日-当日顺序号-中文主题.md`，填写后删除提示文字。纯文档整理不创建产品版本号。

## 基本信息

- 日期：填写实际日期。
- 类型：功能 / 修复 / 架构 / 文档。
- 分支：development。
- 关联提交：填写已存在的提交或提交主题，不预填不存在的 SHA。
- 产品版本：仅正式发布时填写。

## 本次变更

说明用户可见变化、涉及模块以及改动原因。

## 影响范围

说明配置、数据、接口和兼容性影响；纯文档调整明确说明业务代码是否变化。

## 验证结果

| 检查 | 实际结果 | 证据与边界 |
| --- | --- | --- |
| 按范围填写 | 通过 / 失败 / 未执行 | 命令、报告和验收文档 |

只写真实结果，区分本地、远端 CI、浏览器操作、真实后台和用户验收。

## 升级与回退

写清安装或配置迁移步骤、前提、数据备份和可用回退方式。无数据迁移时明确说明。

## 未完成项与风险

记录限制、延期能力和下一步，不将计划写为已实现。

## 关联文档与升级清单

- [ ] 已更新当前状态、配置或使用说明。
- [ ] 已关联实施计划和验收记录。
- [ ] 已更新本月索引、版本总索引；新月份已加入月份表。
- [ ] 文档审计通过；功能变更完整发布检查通过。
- [ ] 已说明本地提交、远端推送和发布状态。
