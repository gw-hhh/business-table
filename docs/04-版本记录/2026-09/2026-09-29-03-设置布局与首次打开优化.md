# 设置布局与首次打开优化

## 范围

按用户反馈优化第一次打开表格设置/模板的等待体验，并整理工具栏、操作按钮、列设置和条件标记布局。日常开发继续在 development。

## 架构与变更

- FeatureHost 使用共享模块加载器，入口移入/聚焦只预加载代码；实际激活仍检查当前配置并创建上下文。预加载与点击合并同一请求，失败后释放待定状态。
- 公共 `preloadFeature` 与本地 `ToolDefinition.preload` 连接通用工具条；Demo 仅声明入口回调。设置打开目标在激活前准备，避免先挂载快捷面板再切完整抽屉。
- 模板编辑器保留按需加载，预加载不创建 Tiptap 实例；弹层即时给出加载/失败状态。
- SettingsSection 统一最后一个折叠按钮，SettingsRange 移除正常范围文案。工具和操作配置共用紧凑行样式，保留拖动、键盘移动、权限与草稿。
- 共享筛选编辑器自己加载基础样式，条件标记不再依赖先打开组合筛选。条件标记重排条件/样式行并提供文字预览；表格标记不再添加图标。ViewsPanel 用可访问的浅黄色圆点表示修改，Demo 移除视图旁重复条数。
- 移除设置备份模块及其读写处理。Preference/View 持久化、业务报价 JSON 备份保持独立。

## 用法与兼容

无需迁移已保存配置。新增预加载回调仅来自可信本地代码，不序列化。字段范围、能力守卫、实际筛选值和业务文案保持原有语义；设置文件导入/导出 UI 已按要求移除。

## 风险与发布

预加载不能消除挂载成本，无意图等待的直接点击仍需初始化。开发服务器与生产预览性能不同；浏览器结果不代表真实后台或全量旧版视觉验收。推送 development 不等于 npm 发布或合入 main。
