# 剩余数据工具对齐

## 基本信息

- 日期：2026-09-23；类型：功能与通用 Runtime 调整；分支：development。
- 关联提交说明：`feat: align remaining data tools and exclude settings history`；提交号以对应 Git 记录为准。本地 development，未推送。
- 产品版本：未正式发布，本次不新增版本号。
- 用户确认范围：条件标记、分组汇总、记录对比、区域选择；明确排除设置历史。

## 本次变更

1. 四项数据工具分别接入 Feature Gate、按交互加载的默认界面，以及 Custom／Headless Context；报价 Demo 通过通用工具菜单打开，业务字段定义仍留在 Demo。
2. 条件标记按原值类型校验，首条启用规则命中后投影到行。可选规则贯通 TableConfig、Preference v3 和 View；系统视图保留布局标记。写入使用现有配置队列，保存成功后才发布，失败保留旧规则和草稿。
3. 分组汇总和记录对比复用当前完整查询读取，支持两级分组、2–4 条记录对比、十进制数值汇总及按需 XLSX 导出。完整结果接口缺失时报告错误，不以当前页充当全量。
4. 区域选择限定当前页可见数据列，支持矩形选区、键盘扩选、TSV 复制和数值统计；选区不持久化，也不改变业务行选择。

## 影响范围与兼容

- 四项默认关闭；旧接入未声明时不出现入口。远端权限只能收窄列及功能，显式 disabled 保留已有合法值的查看能力。
- `TableConfig`、`PreferenceV3`、`ViewConfig` 新增可选 `conditionalFormatting`；原 schemaVersion 保持不变，旧记录缺少该字段时可继续读取。空数组是显式清空。
- `ConfiguredBusinessTable` 新增可选 `savePreference: (value: PreferenceV3) => Promise<void>`，提供后由 Runtime 等待保存成功。原 `preferenceChange` 事件仍发出差量，但事件监听本身不构成保存确认。
- 分组、对比和区域选择没有新增持久化协议。分组与对比的远程接入需要 `DataSource.readAll` 返回当前完整查询结果。
- 设置历史不迁移，不新增状态、按钮或存储键。

## 升级与回退

接入方显式声明四项 Feature，并按需要提供列定义、完整查询读取和可等待的 Preference 保存函数。旧配置无需数据迁移；远端持久化接入前，应在后台确定用户/租户范围、鉴权和并发版本策略。本地共享分支需回退时使用恢复提交，不改写历史或参考文件。

## 未完成项与风险

真实后端的完整查询、Preference 写入与权限、并发版本，以及服务端大数据导出仍需业务适配验收。浏览器几何与交互结论限定于本批记录场景，不宣称全部视口逐像素一致。设置历史已从本次及后续待办中排除。
