# 组合筛选与查询摘要对齐

## 基本信息

- 日期：2026-09-23；分支：development，接续 f7fe5c9。
- 类型：功能对齐与通用 Runtime 调整；产品版本保持 1.0.0，未正式发布。
- 用户确认范围：先完整对齐组合筛选及方案、摘要和视图联动。

## 本次变更

1. 报价页提供“数据工具 → 组合筛选／工具栏设置”，菜单通过通用工具声明接入。未实现项保持隐藏。
2. 组合抽屉按旧版 580px 宽度、条件卡片、空态、按钮顺序和日期文案对齐；保留嵌套 AND/OR。平台独立筛选方案移到标题区的“筛选方案”窗口，支持创建、更新、重命名、删除和载入草稿。
3. 筛选方案 Runtime 移入 Filters Context，默认、Custom、Headless 共用；Feature 生命周期释放，撤销后旧命令拒绝，存储失败保留编辑内容。
4. 可选 querySummary 汇总基础查询、列条件和组合条件。“清除条件”一次重置三个层次；移除单个 Search 标签不再提交其他草稿。
5. 组合条件按嵌套逻辑生成可查看的摘要；标签按原值类型匹配，重复字段合并远端回查，迟到响应失效。Query、Plan、View 继续保存实际值。

## 影响范围与兼容

- querySummary 默认关闭，已有 after-toolbar 插槽与 SearchSummary 接入继续有效；选择统一摘要后需移除重复摘要插槽。
- FiltersContext 不再暴露原始 persistence，Custom/Headless 调用方改用 context.plans 与 context.readPlan(id)。宿主仍通过 filterPlanPersistence 传适配器，原 v1 方案协议和存储键不变。
- 工具声明新增 children，现有 handler、插槽和工具布局偏好继续兼容；父工具偏好不改写子项权限。
- 清除查询保留排序、布局和 View 标识，基础值遵循 resetBehavior；View 会按实际已应用查询判断是否未保存。
