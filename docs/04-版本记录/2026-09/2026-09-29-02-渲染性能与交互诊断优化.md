# 渲染性能与交互诊断优化

## 范围

在 development 增加原生虚拟滚动、查询计算缓存、通用空状态、共享动效和配置来源诊断。设置历史继续排除；默认列宽双击恢复、配置权限和既有数据协议保持原义。

## 架构与配置

- TableSurface 共用 `TableRenderingOptions`，所有表格入口透传高度/虚拟窗口；Preference/View 不保存渲染环境。
- Query Runtime 为可追踪定义缓存签名，普通可变输入保留即时检查；本地缓存键缩为相关列字段/映射顺序，关闭自动提交时停止草稿签名订阅；条件标记复用匹配列 ID。
- `#empty` 提供独立查询快照、结果原因和恢复命令，业务自行组织按钮。
- 共享定位提供 close/follow 外部滚动策略；受控 DialogFrame/AnchoredPopup 与 useMotion 管理进入/退出；键盘排序复用 Sortable 动画。
- `searchPanel.animateCollapse` 可选启用区域高度动画；列宽拖动显示即时像素数。
- 显式 `explainConfiguration` 解释传入快照的列/分页/外观来源，不等同于在线 Inspector 或设置历史。

## 用法与兼容

虚拟滚动默认关闭，使用原生自动行高，无额外渲染引擎。搜索动画默认关闭，原有 display:contents 布局保持。弹窗调用方使用持续挂载的 open 属性才能完成退出动画；整个页面/Feature 卸载时立即释放资源。
