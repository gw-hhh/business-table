## 本次变更

开放公共 useTableRuntime 与 BusinessTableGrid、SearchRegion、SearchToggle、TablePagination、TableTools，支持外置搜索和独立布局。默认 BusinessTable 保留原有完整组合，新增 ESM runtime/components 子入口及真实公开包 ComposedTable 示例；Demo 提供双实例预览。

分页新增页码、显示开关、单页隐藏、对齐、样式与完整读取上限。隐藏分页栏仍按页执行；关闭分页时本地返回完整查询，远程要求 readAll 完整接口且受上限约束。搜索区域显隐保留草稿，高级条件展开单独管理，可选显示偏好存储与自动提交防抖。

富文本编辑使用 Tiptap 3.31.3，既有 RichDocument 和字段稳定 ID 继续保存；拖动改用 SortableJS 1.15.7，由共享层复查权限、恢复 DOM 后交给原有移动命令；浮层使用 @floating-ui/vue 2.0.1，统一尺寸与边界观察、翻转、就绪焦点和关闭清理。依赖版本以锁文件为准。

本地查询按数据/条件/列解释复用筛选排序结果，条件标记按当前页每行计算，再供该行各单元格复用。构建增加公开子入口与依赖审计，ESM 保持按交互分块，UMD 继续单文件。性能收益以实际测量为准。

## 影响范围

- 新 API 为增量，根包原有导出及默认表格接法保留。Runtime 子入口不导入 UI/VXE/CSS，组件宿主显式加载既有样式。
- RichDocument、Preference、View 与业务动作协议不迁移；编辑器历史、拖动瞬态和浮层坐标不写入持久化。
- 查询区域显示偏好使用独立同步适配器；远程完整查询和防截断语义由业务数据源承担。
- 独立 Grid 是基础表体组合，高级 Feature 面板需宿主显式接入或继续使用 BusinessTable。
- reference 保持只读；设置历史仍不在范围内，规则试算仍不等于公式引擎。

## 升级与回退

按锁文件安装依赖。已有默认入口无需改为组合式接法；新增接法见[组件组合与分页](../../02-架构与规范/12-组件组合与分页.md)。关闭远程分页前必须提供符合上限与取消信号契约的 readAll，不能只改 pageSize。

本次不要求迁移持久化格式。需要回退时，恢复本批以前的应用代码和对应锁文件；保留既有业务数据及个人偏好，不通过清空存储回避兼容问题。正式发布和 main 合并须另行安排。

## 未完成项与风险

ESM 支持动态加载，UMD 保持单文件；Demo 的 VXE 共享块仍有体积提示。真实 Windows 输入法候选窗口与远端 CI 未单独验收。真实后台查询、鉴权、服务端版本冲突与用户体验验收不由本地类型或模拟测试替代。旧版全量视觉验收和公式引擎仍属于后续工作；设置历史按用户要求排除。
