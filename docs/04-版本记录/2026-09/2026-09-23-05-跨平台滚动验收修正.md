# 跨平台滚动验收修正

## 基本信息

- 日期：2026-09-23。
- 类型：测试与验收规范修正。
- 分支：development；接续文档整理提交 `b476446`。
- 产品版本保持 1.0.0，无正式发布。

## 本次变更

`b476446` 的 Linux CI 在开发和构建预览中均发现旧版可用表体高度 352px、Vue 表体高度 353px，严格等高断言失败。远端 trace 显示横向滚动条高度为 0。跨页面高度比较采用与同文件其他几何检查一致的 1 CSS 像素容差，并增加 Vue 本页容器、表头和表体的高度预算检查；横向滚动条严格为 0、纵向实际可滚动的断言保留。

完整复验另发现固定列滚动用例的就绪条件不足：6 行 DOM 已出现时异步操作列尚未挂载，滚轮输入早于横向范围形成。现先等待实际横向可滚动范围达到输入的 150px，再操作滚轮；原滚动距离和固定边缘位置断言保留。

## 影响范围

仅修改浏览器测试及说明。平台 Feature、Runtime、Config、Persistence、业务界面、依赖和旧版参照均无变化，不增加平台判断或样式补丁。
